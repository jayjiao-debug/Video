## 2. 题材和文案

**核心创意：** 每一宗罪先作为一个「角色」登场；下一个强拍，一道刀光把它从中间切开，两半向两边滑开。从切口深处，一个社会主义核心价值观的词迎面走来（从远处由小变大、由虚变实地飞到观众面前）。七宗罪切完，结尾二十四字的十二个价值观全部亮起。

**事实依据（只写这些，不要编）：**
- **七宗罪：** 公元 6 世纪由教皇格里高利一世（St. Gregory the Great）列出。可写作「公元6世纪，教皇格里高利一世列出了七宗罪」。
- **社会主义核心价值观**（二十四字，三个层面）：
  - 国家层面：富强、民主、文明、和谐；
  - 社会层面：自由、平等、公正、法治；
  - 个人层面：爱国、敬业、诚信、友善。

**七组对应（建议稿，可以改，但要一一对应、讲得通）：**

| # | 罪 | 颜色 | 罪的象征图形（不画人脸） | 罪说的话 | 切开后迎面走来 | 收尾一句（具体、生活化，不喊口号） |
|---|---|---|---|---|---|---|
| 1 | 傲慢 | 金橙 #ffb43a | 高高的王冠 + 抬起的下巴剪影 | 「就你？」 | 平等 | 谁都不比谁高一头。 |
| 2 | 嫉妒 | 毒绿 #9be35a | 一只发绿光的眼睛 | 「凭什么是他？」 | 友善 | 替别人高兴，也是一种本事。 |
| 3 | 暴怒 | 火红 #ff4a2a | 握紧的拳头 + 火焰 | 「你再说一遍？」 | 和谐 | 先把火放下，话才说得清。 |
| 4 | 懒惰 | 灰蓝 #7aa6ff | 一只蜗牛 / 一个枕头 | 「明天再说。」 | 敬业 | 把手上这件事做完，就是敬业。 |
| 5 | 贪婪 | 暗金 #e6c47a | 抓满金币的手 | 「再多拿一点。」 | 法治 | 不该拿的，一个都不拿。 |
| 6 | 暴食 | 橘粉 #ff8a5c | 张大的嘴 + 叠高的外卖盒 | 「就吃一口。」 | 文明 | 光盘，是对粮食的文明。 |
| 7 | 色欲 | 紫 #c47bff | 带刺的心 | 「再看一眼。」 | 诚信 | 说过的承诺，要守住。 |

每一宗罪有四行字：
1. **场景句：** 「它在你____时说」，≤ 12 字，例：它在你看不起别人时说。
2. **罪的原话：** 一句很短的口语（上表），大字。
3. **切开句：** 「切开「傲慢」，迎面走来的是——」。
4. **价值观大字**（两个字），然后是收尾一句。

**片头（2 小节）：**
- 「公元6世纪，教皇列出了七宗罪。」
- 「今天，我们把它们一宗一宗切开。」
- 七个罪名小圆标依次弹出，每半拍一个。

**片尾（约 6 小节）：**
1. 「七宗罪切开以后——」。
2. 十二个价值观排成三行（国家、社会、个人），在拍子上依次出现，用到的七个更亮。
3. 一个问题：「你最想先切开哪一宗？」（问号要居中，见第 9 节）。
4. 在一个强拍上，标题砸进来：「切开七宗罪」，下面一行小字：「迎面走来的，是社会主义核心价值观」。

**分寸：**
- 价值观是「好的一方」，要庄重、好看，不调侃。
- 不用国旗、国徽、真实人物或领导人形象，不出现地图。
- 罪用象征图形，不用真人或真人梗图。
- 收尾句写具体行为，不写空话。我们的冷读测试里，说教的收尾句是观众最先划走的地方。

## 3. 结构和卡点（照《七情》）

《七情》的骨架：
- 片头 2 小节；
- 每个角色 3 小节；
- 片尾提问，标题砸在一个回来的强拍上；
- 文字永远在左，画面永远在右，观众知道该往哪看。

这次每一宗罪多了「切开」这一步，所以**每宗罪 4 小节**：

| 小节 | 发生什么 |
|---|---|
| A | 场景句 + 罪的原话迎面走来（左）。右边是一个封着的圆盘，罪的剪影隐约可见，最后两拍剪影的眼睛或图形亮起来（预告）。 |
| B（强拍） | **罪登场。** 这一帧罪名大字和图形同时出现（不淡入）。同时：一帧微亮、两道细圆环扩散、名字横向动态模糊收回、粒子散开。第 3 拍，这宗罪自己的「活动元素」动起来（王冠落下、绿火、拳头冒火、蜗牛爬、金币落、外卖盒叠高、心长刺）。 |
| C（强拍） | **切开。** 前半拍画面先停住（蓄力），强拍这一帧一道刀光斜着划过，图形沿切线一分为二向两侧滑开，切缝发光、漏出光粒子。切开句同时出现。第 2 拍，价值观两个大字从切缝深处迎面走来，落定，落定时一个圆环。 |
| D | 价值观大字停在画面中间偏右，收尾句迎面走来（左下）。小节末尾，用价值观的颜色做圆形遮罩转场（iris）进入下一宗罪。 |

**时间公式：** 一切时间都由音乐网格算出来，不要手填秒数。

```ts
const FPS = 30;
const BPM = 118.37;                 // 用第 7 节的脚本测出来
const BEAT = 60 / BPM, BAR = 4 * BEAT;
const T_DROP = 6.14;                // 你听出来的第一个大拍（drop）的时间，秒
const PH = T_DROP - 3 * BAR;        // 让第一个大拍正好是第 3 小节（片头 2 小节之后）
const bt = (n: number) => PH + n * BAR;          // 第 n 小节的强拍时间
const snap = (t: number) => Math.floor(t * FPS + 1e-6) / FPS;  // 对齐到"包含这个拍子的那一帧"，绝不晚一帧
// 第 i 宗罪 (i = 0..6)：A = bt(2+4i)，B = bt(3+4i)，C = bt(4+4i)，D = bt(5+4i)
// 片尾从 bt(30) 开始，标题砸在 bt(34)，成片到 bt(36) + 0.6 s 左右
```

**注意：**
- 片头要压缩：如果 T_DROP 比 2 小节早或晚，就让片头长度跟着它走。原则是第一个大拍 = 第一宗罪登场。
- 字幕可以跨小节。阅读时间（第 9 节）优先于整齐。场景句可以从 A 的强拍一直留到 B 的第 2 拍。

## 4. 画面风格（《七情》的样子）

- **背景：**
  - 近黑的径向渐变，中心带一点这宗罪的深色（例：暴怒是 #2c0704），四周 #030205。
  - 50 个缓慢闪烁的小星点。
  - 一个很大的细线圆，在左侧当底纹。
- **主体：**
  - 右侧中心（约 x=1400, y=500）一个圆盘光环，像玉璧，带金边 #e6c47a 和这宗罪的颜色。
  - 罪的象征图形在光环里，用霓虹线条画（亮芯 + 外发光），**不画脸、不画手指**。
  - 我们的经验：画得不对的解剖结构比不画更糟。象征物比人物可靠。
- **配色：** 每宗罪一个主色 + 一个亮色（接近白）+ 一个深色。价值观统一用暖金到正红（#ffd27a → #e8392b），庄重、暖，和罪的冷暗形成对比。
- **字体：** 思源宋体 / Noto Serif CJK SC（开源，OFL 授权）。
  - 罪名大字约 330 px，渐变填色（白 → 亮色 → 主色），后面一层模糊光晕。
  - 罪的原话约 92 px。
  - 场景句约 42 px。
  - 收尾句约 48 px，加粗。
- **元素少而干净：** 每个场景最多一个「活动元素」。七个场景用同一个模板，但活动元素必须各不相同，不然到第 3、4 宗罪观众会觉得重复（我们的冷读测试在第 22–25 秒出现过这个问题）。

## 5. 关键动效的做法

### 5.1 迎面走来（所有字幕和价值观大字）

把文字放在一个「从远处飞到面前」的变换里。在消失点附近从小变大，同时去模糊：

```tsx
// u: 0 → 1 进场进度（约 0.35 s，ease-out），out: 0 → 1 离场进度（约 0.2 s）
const s = lerp(0.18, 1, out3(u)) * lerp(1, 1.6, out);          // 由远到近，离场时继续冲过镜头
const blur = 14 * (1 - out3(u)) + 10 * out;                     // 远处是虚的
const o = Math.min(1, u * 1.6) * (1 - out);
// <g transform={`translate(${x},${y}) scale(${s})`} opacity={o} filter={`url(#blur_${id})`}>…文字…</g>
// 在 <defs> 里用 <feGaussianBlur stdDeviation={blur}> 定义 blur_${id}；blur < 0.3 时不加 filter
```

- 进场后必须**完全静止、清楚**地停够阅读时间（第 9 节），不要一直在缩放。
- 价值观大字：从切缝深处（切线中点）飞出来。起点 scale 0.12，同时轻微向上，落定时 scale 1.0。落定这一帧加圆环和金色粒子。

### 5.2 切开

在 C 小节的强拍：
1. **蓄力：** 强拍前半拍，图形停住或微缩（0.97），背景略暗。
2. **刀光：** 强拍这一帧，一条很亮很细的斜线（约 −28°）横过整个光环，长 1200 px，宽 10 px，高斯模糊 3。保留 2–3 帧后变细消失。
3. **一分为二：** 同一个图形画两遍，各用一个 `clipPath` 多边形只显示切线一侧。两半沿切线的法线方向各滑开 70–120 px，轻微反向旋转 ±4°，约 0.45 s，ease-out。
4. **切缝：** 两半之间的缝里是价值观的颜色。暖金的光从缝里透出来，并洒出 20–30 个光粒子。
5. **震动：** 强拍后 0.3 s 内一个衰减的小抖动，最大 4 px。

**不准用整屏白闪。** 「命中」的感觉要靠刀光、圆环、名字的动态模糊和一帧轻微提亮来做：叠一层 0.18–0.55 透明度的白，只持续 1 帧。

### 5.3 登场（B 小节的强拍，照《七情》）

- 图形和罪名在**同一帧**出现，不淡入。
- 名字带横向动态模糊（`feGaussianBlur stdDeviation="46 0"` 在 0.3 s 内归零），从左边 70 px 滑到位。
- 两道细圆环从名字中心扩散（0.85 s）。
- 一道白色光条从名字横扫到图形（0.12 s 伸出，0.35 s 消失）。
- 一帧轻微提亮（见上）。
- 罪名下方一行小字：「七宗罪 · 之一」，金色。

### 5.4 转场

- 场景之间用**价值观颜色的圆形遮罩（iris）**：从价值观大字的位置扩大到盖满全屏，正好在下一宗罪 A 小节强拍那一帧盖满，然后从新场景的圆盘位置打开。
- 不用生硬的交叉淡化：两个场景的人物不能同时半透明叠在一起。
- 镜头运动每帧 ≤ 25 px，不做快速甩镜（手机上会闪）。

## 7. 测音乐网格（tools/beats.py）

```python
# 用法: python tools/beats.py public/music.wav
import sys, numpy as np, librosa
y, sr = librosa.load(sys.argv[1], sr=22050, mono=True)
hop = 256
# 鼓点（低频）起音强度：只看 30–150 Hz，避开踩镲，免得锁到反拍
S = np.abs(librosa.stft(y, n_fft=2048, hop_length=hop)); f = librosa.fft_frequencies(sr=sr)
kick = librosa.onset.onset_strength(S=librosa.amplitude_to_db(S[(f > 30) & (f < 150)]), sr=sr, hop_length=hop)
tt = librosa.frames_to_time(np.arange(len(kick)), sr=sr, hop_length=hop)
tempo = float(np.atleast_1d(librosa.beat.beat_track(onset_envelope=kick, sr=sr, hop_length=hop)[0])[0])
best = (0, 0, 0)
for bpm in np.arange(tempo * 0.98, tempo * 1.02, 0.01):            # 在估计值附近细搜拍长和相位
    beat = 60 / bpm
    for ph in np.arange(0, beat, 0.005):
        idx = np.searchsorted(tt, np.arange(ph, tt[-1], beat))
        sc = kick[np.clip(idx, 0, len(kick) - 1)].mean()
        if sc > best[0]: best = (sc, beat, ph)
_, beat, ph = best
print(f"BPM {60/beat:.2f}  BEAT {beat:.4f}s  鼓点相位 {ph:.3f}s   （拍 k 的时间 = {ph:.3f} + k × {beat:.4f}）")
low = S[(f > 30) & (f < 150)].sum(0)
for k in range(int((tt[-1] - ph) / beat))[:96]:
    t = ph + k * beat; e = low[(tt >= t - 0.03) & (tt < t + 0.08)].mean()
    print(f"拍 {k:3d}  {t:7.3f}s  鼓 {'█' * int(30 * e / low.max())}")
```

**怎么用：**
1. 先听歌，找到第一个「大拍」（鼓重新进来、最炸的那一下），记下秒数，就是 T_DROP。
2. 用脚本的输出确认它落在一拍上：鼓点条突然变短的那一拍是鼓停（break），紧接着变回长条的那一拍就是大拍。
   起音检测通常比真正的鼓头晚约 20 ms，网格整体可以再提前 0.02 s。（用《七情》的歌实测：脚本给出 118.35 BPM、相位 0.080 s，人工校准为 118.37 BPM、0.06 s，第 11 拍鼓停，第 12 拍 6.16 s 是大拍。）
3. 把 BPM 和 T_DROP 写进 `grid.ts`。

**选歌建议：**
- 鼓点清楚、4/4 拍、100–125 BPM。
- 中间最好有一两处鼓停（break），用来放「切开」前的蓄力或片尾提问。
- 标题砸在鼓回来的那一拍上最有力。
- 抖音上传时，在曲库里选同一首歌做配乐，原声 100、配乐 0，以免版权匹配出问题。

## 8. 合成和导出（ffmpeg）

```bash
# 1) 把音乐裁到片长，响度标准化到 -14 LUFS / -1.5 dBTP
#    START = 你测网格时用的起点（秒），DUR = 片长（秒），FADE = DUR - 1.5（自己算好填数字，例：DUR=73.6 → FADE=72.1）
ffmpeg -ss START -t DUR -i music.mp3 -af "afade=t=out:st=FADE:d=1.5,loudnorm=I=-14:TP=-1.5:LRA=11" -ar 48000 mix.wav
# 2) 高清原片
ffmpeg -i out/pic.mp4 -i mix.wav -map 0:v -map 1:a -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p \
  -c:a aac -b:a 256k -shortest -movflags +faststart 切开七宗罪_高清.mp4
# 3) 发送版 ≤ 28 MB（720p 两遍编码，约 1.6 Mbps；Windows 上把 /dev/null 换成 NUL）
ffmpeg -y -i out/pic.mp4 -vf scale=1280:720 -c:v libx264 -b:v 1600k -pass 1 -an -f mp4 /dev/null
ffmpeg -i out/pic.mp4 -i mix.wav -map 0:v -map 1:a -vf scale=1280:720 -c:v libx264 -b:v 1600k -maxrate 2400k -bufsize 4800k \
  -pass 2 -c:a aac -b:a 128k -shortest -movflags +faststart 切开七宗罪_发送版.mp4
# 4) 复查响度
ffmpeg -i 切开七宗罪_高清.mp4 -af ebur128=peak=true -f null - 2>&1 | tail -12
```

**注意：** 如果 `pic.mp4` 是从歌的中间某段开始对拍的，START 必须就是你测网格时用的那个起点，否则全片会错拍。

## 9. 检查清单（每一轮都要过，人看 + 脚本）

### 9.1 自动检查

**阅读时间（tools/pace.py）：** 每行字至少要在画面上停留 `0.5 s + 字数/7 + 0.6 s`。古文和带数字的行再加 0.25–0.4 s。读完了还停太久的总和不超过全片的 12 %。

```python
# 用法: python tools/pace.py lines.json   (lines.json = [[开始秒, 结束秒, "文字"], ...]，由 data.ts 里的时间导出)
import json, re, sys
L = sorted(json.load(open(sys.argv[1]))); wait = 0
for s, e, t in L:
    n = len(re.findall(r'[一-鿿]|[A-Za-z]+|\d+', t)); need = 0.5 + n / 7 + 0.6; on = e - s
    tag = '太快' if on < need - 0.25 else ('久等' if on > need + 1.5 else '')
    wait += max(0, on - need - 1.0); print(f"{s:6.2f}-{e:6.2f} {n:3d}字 在屏{on:4.1f} 需要{need:4.1f} {tag} {t}")
print(f"等待合计 {wait:.1f}s ({100 * wait / L[-1][1]:.0f}%)，目标 ≤ 12%")
```

**单帧闪烁 / 坏帧（tools/glitch.py）：** 找出「和前后两帧都不同、而前后两帧彼此相同」的帧。

```python
# 用法: python tools/glitch.py out/pic.mp4
import subprocess, sys, numpy as np
w, h = 160, 90
raw = subprocess.run(['ffmpeg','-loglevel','error','-i',sys.argv[1],'-vf',f'scale={w}:{h}','-f','rawvideo','-pix_fmt','gray','-'],capture_output=True).stdout
F = np.frombuffer(raw, np.uint8).reshape(-1, h, w).astype(np.float32)
for i in range(1, len(F) - 1):
    dp, dn, ds = (np.abs(F[i]-F[i-1]).mean(), np.abs(F[i]-F[i+1]).mean(), np.abs(F[i+1]-F[i-1]).mean())
    if min(dp, dn) - 2.5 * ds > 1.5: print(f"可疑帧 {i/30:7.3f}s  ({min(dp,dn):.1f} vs {ds:.1f})")
```

被标出来的帧要一张张看：
- 刀光、一帧提亮这类故意的效果可以保留；
- 东西消失一帧、颜色跳一帧，都是 bug。

**卡点误差：** 每个「登场 / 切开 / 价值观落定 / 标题」的命中帧，都要等于 `snap(拍子时间)` 那一帧，误差 ≤ ±1 帧（33 ms）。在代码里把这些时间打印成表格交给人核对。

**联系表（tools/sheet.py）：** 每 2 秒一张、每个命中前后各一张，拼成网格图，一眼看完全片。
