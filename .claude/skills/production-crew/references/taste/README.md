# Taste board

Frames that show what the owner means by good and bad, each with one line on why. Agents read this before
proposing looks or reviewing stills: a picture with a reason teaches more than an adjective.

How to add a frame:
- Save it here as a JPG (≤ ~300 KB; never video or music, the repo is public), named `<ep>-<what>.jpg`.
- Add a row below: the file, LOVED / REJECTED / FIXED, and the reason in one line (quote the owner if he said it).
- Every time the owner rejects or praises a frame, it goes here.

| File | Verdict | Why |
|---|---|---|
| `ep35-push-before-after.jpg` | FIXED | Pushing = palms flat on the object, head clear of it, back leg driving, feet on the slope. Before: head on the rock, arms hanging ("The position of rock pushing is not right"). The light pool now follows the slope. |
