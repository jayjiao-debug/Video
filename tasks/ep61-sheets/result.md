## 做了什么
- **19 张设定图**（`SHEETS61`，1440×1080，30 fps，帧 i = 第 i+1 张）：
  - 第 1 张是总排：17 位同地平线、同比例尺，加脸的索引和身高规则。
  - 第 2–18 张是 17 位角色：阿图姆·拉合一张，另有舒、泰芙努特、盖布、努特、奥西里斯、伊西斯、赛特、奈芙蒂斯、荷鲁斯、阿努比斯、托特、塞赫迈特、巴斯特、玛阿特、阿米特、阿尼。
  - 第 19 张是道具表，含心脏、羽毛、天平、ankh、was、弯钩与连枷、叉铃、调色板与笔、圣甲虫、正面面具，另有一排握法特写。
- **每张角色表**包含：
  - 主视图和引线标注，标注带出处（I 行、博物馆、编号）。
  - 色板：hex 取自代码里的 PAL / cast 颜色。
  - 必须 / 不要。
  - 身高标尺：阿尼头顶线，加渲染后量出的含冠总高。
  - 4 个关键姿势，3 个关节压力姿势（红点是关节枢轴，虚线是骨链）。
  - 3 种表情的头部特写，外加一行部件，如下颌、喙、耳、翅、眼各 3–4 档。
- **画的是影片用的同一批组件**：`God`、`God61`、`Ammit2`、`Balance2`、`HeartScarab`、`MaskFront` 等，设定图和影片不会漂移。
- **`RIGTEST61`**：17 位 × 6 秒，共 3060 帧。顺序是走、标志动作、3 个压力姿势、表情切换，旁边有头部大特写。
- **骨架新增的动作**（默认关闭）：
  - 豺、朱鹮、隼的下颌或喙张开，豺耳折叠。
  - 狮首怒吼：下颌最大 59°，带獠牙和舌，头后仰。
  - 猫和 Set 兽的耳朵旋转。
  - 眼睛睁/半/闭、看向，眉扬/皱，人脸微笑、小张嘴。
- **身高规则**：身体 = 凡人 × 1.00，阿尼连假发实测 20.1 格。含头饰总高从盖布 19.9 到奥西里斯阿特夫冠 24.2 格，即 ×0.99～×1.20；孩童荷鲁斯 ×0.75。阿米特是独立小骨架，在 ep60 称重厅里 s=34，阿尼 s=26。
- **设计册**：`designbook.md` 写了每个角色的考据和出处、色板 hex、比例、标志动作、必须/不要、关节、帧索引，以及以后每集该 import 哪些组件。

## 渲染命令
```

# 19 张设定图（SFPS=1 让“秒数”等于帧号，文件名 f_<帧>.0.jpg）
SFPS=1 ENTRY=qq61/sheets61 CID=SHEETS61 JPG=1 node scripts/frame.mjs stills /tmp/sheets $(seq 0 18)
# 关节动画抽帧：第 k 位从帧 180·(k-1) 开始。例：托特（第 12 位）的走、标志动作、压力姿势、表情

# 整段 102 秒
ENTRY=qq61/sheets61 CID=RIGTEST61 node scripts/frame.mjs video /tmp/rigtest61.mp4 0 102
```
