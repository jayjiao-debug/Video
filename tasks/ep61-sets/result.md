# ep61 布景库：做完了

我们这一系列现在有自己风格的布景库：建筑、自然、道具、动物、群众、氛围动效，一共 69 格。全部是纯 SVG 组件，参数是 `(x, y, s, t)`，会动的都由 `t` 驱动。另做了目录、3 个示例场景和一条 27 秒的动效片。所有画面都在 runner 里渲染出来，我按全尺寸逐张看过，并改掉了重叠、裁切、遮挡和文字溢出。

代码和 markdown 已提交（`5e23f6d`），没有提交任何图片、视频、音频。只新增文件，没有改任何已有文件，cast61 / chars61 / heads61 / rig60 都没动，所以 ep60 和 ep61 的画面不会变。

## 库里有什么
- **比例**：单位 = 角色骨架的“格”（阿尼 20.1 格高）。布景和演员用同一个 `s`，就是真实比例。
- **建筑（15 格）**：
  - 塔门：旗杆上的三角旗会飘，门内有火光。
  - 纸草束柱和莲花柱，开、合两种柱头。
  - 额枋加有翼日轮、方尖碑、坐像巨像。
  - 狮身人面像、羊首狮身像大道。
  - 神龛、狮足王座、阶梯高台、假门。
  - 小金字塔墓礼拜堂、金字塔群、马斯塔巴、王宫显现之窗。
- **自然（11 格）**：
  - 尼罗河（水纹漂流、涟漪、闪光）、会摇的纸草丛、花开花合的莲池、椰枣树。
  - 扬沙的沙丘、有流星的星空、akhet 地平线上的日出和日落。
  - 努恩原初之水、从水里升起的本本石丘、血色天空。
- **道具（18 格）**：
  - 堆满的供桌、啤酒罐、冒烟的立式香炉和手臂形香炉、油灯、火盆（火焰加火星）。
  - 四子卡诺匹斯罐、纸草卷、书吏调色板、棋子会跳格的塞尼特棋、会摇响的叉铃。
  - 安卡、瓦斯权杖、杰德柱，太阳船，纸草小舟，狮形葬床，木箱，篮子，鸵鸟羽扇。
- **动物（11 格）**：
  - 隼：栖着时会转头、眨眼，也有飞的版本。
  - 朱鹮会啄水，猫会甩尾，眼镜蛇会膨颈吐信。
  - 圣甲虫推球、水中的鳄鱼、雁阵、牛、卧在神龛上的豺、水下的鱼。
- **群众（7 格）**：全部用 ep60 骨架，每个人有自己的相位，不会整齐划一。
  - 抬圣船神龛的祭司队列，领头者拿着冒烟的香炉。
  - 哭丧者、拖石块的工人、头顶篮子的工人。
  - 竖琴、叉铃乐师和舞者，持矛执盾的士兵，执扇者。
- **氛围动效（7 格）**：火焰、烟雾卷曲、浮尘、飞鸟掠过、水面波光、光柱、火星。

## 示例场景（`SCENE61`）
1. **夜·神庙前庭**：星空和金字塔，塔门，方尖碑，羊首像大道，祭司队列，火盆，猫，加上阿努比斯。
2. **黄昏·尼罗河**：日落，沙丘，椰枣树，雁阵，河上有撑篙的阿尼、鳄鱼和朱鹮，近景是纸草丛。
3. **供奉大厅**：星顶，文字墙，柱子和额枋，光柱，点着灯的神龛上卧着豺，供桌，香烟，油灯，卡诺匹斯罐，加上伊西斯和阿尼。

每个场景右上角都有一张图层表，写明背景、中景、前景、角色和光各用了哪些组件。

## 出处
- **核实情况**：研究员核实了每件的来源，52 条中 49 条是亲自打开过的 Met、UNESCO 或卢浮宫官网记录。目录每格都带出处标签，全表连同网址在 `tasks/ep61-sets/out/sources.md`。
- **没有可考实物、按设计选择标注的**：
  - 显现之窗、高台形制、葬床的狮头。
  - akhet 日出、努恩之水、沙丘、血色天空。
  - 手臂形香炉的造型、鸵鸟羽毛、圣甲虫推粪球（文物上多是托着日轮，组件里有 `sun` 开关可以换成日轮）。
