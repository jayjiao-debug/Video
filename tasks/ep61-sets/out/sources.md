# ep61-sets: verified sources for the set-dressing library

Checked 2026-11-06 by the researcher. No Wikipedia, 百度百科 or 知乎 were used.

**What the status means**
- **✓** I opened the museum record myself (the Met Open Access API `/public/collection/v1/objects/<id>`). The title, accession number and date below are copied from that record. MET = `https://www.metmuseum.org/art/collection/search/<id>`.
- **✓ img** I also looked at the object image.
- **(unverified)** I could not open the source from here. The British Museum returns 403, the Louvre collections site returns 429 (bot wall), and Cairo/GEM have no open records. The animator may use these only as a secondary visual reference and should cite the verified Met row instead.
- Unless a row says **✓ img**, the design notes describe the standard Egyptian form named in the record's title. I did not check each image one by one.

**API note for the next person:** the Met retired `/public/collection/v1/search` on 2026-10-01 (HTTP 410). Use `/public/collection/v1.1/search?q=...&departmentId=10&limit=N` instead. Fast parallel calls trigger an Incapsula block, so send requests one at a time with about 1.5 s between them.
