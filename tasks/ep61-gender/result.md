# ep61 第 3 轮：黑假发、头饰和签名色已完成

所有角色现在在手机小屏上都能一眼分开。人头的神改成黑假发，各戴自己的头饰。每位角色有一个签名色，用在裙子或短裙上，同一个颜色也出现在家谱的节点环、名字牌和设定表上。代码和 markdown 已提交（`526338b`），没有提交图片、视频或音频。ep60 没有变化：EP60PIC 第 1500、2500、4300 帧改前改后逐像素相同。

## 改了什么
- **假发**：人头的神一律黑假发，包括阿图姆、舒、盖布、努特、伊西斯、奈芙蒂斯、玛阿特。青金蓝假发只给兽头神：阿努比斯、荷鲁斯、拉、托特、赛特、泰芙努特、塞赫迈特。
- **头饰**：
  - **伊西斯**：新画了秃鹫头冠。金色鸟身盖在假发上，翅膀垂在两侧，鸟头在额前；冠顶有金色托座，上面是王座符。
  - **奈芙蒂斯**：金头箍 + 房屋篮子符。
  - **玛阿特**：红头带，羽毛插在头带里。
  - **努特**：素黑假发，不戴头饰。她不再戴 nu 罐，影片里星拱上的红罐也去掉了。
  - **舒**：黑假发 + 羽毛。
  - **盖布**：头顶的鹅。
  - **阿图姆**：黑假发上戴红白双冠。
  - **画在哪一层**：头饰现在画在骨架自己的头层里，举手时手臂会盖在头饰前面。
- **签名色**（裙子或短裙）：
  - **女神**：伊西斯红（不加金网，免得远看成橙色）、奈芙蒂斯绿、努特深蓝星空裙（60 颗金星）、玛阿特白裙 + 金网、泰芙努特赭金、塞赫迈特深绯红、巴斯特绿松石。
  - **男神**：赛特红赭、荷鲁斯蓝 + 金、拉金 + 红、阿努比斯黑 + 金、托特白裙 + 深蓝腰带、舒天蓝、盖布土褐 + 绿腰带、阿图姆白裙 + 红腰带。
  - **奥西里斯**：保持绿皮肤 + 白裹布。
- **长得像的两对**：
  - **塞赫迈特和泰芙努特**：塞赫迈特多了一圈更厚、更深的鬃，头色也更深。
  - **荷鲁斯和拉**：荷鲁斯戴双冠，拉戴日轮 + 圣蛇，裙色也不同（蓝 / 金）。
- **家谱（TREE61、BOARD61 的小家谱）**：节点环用签名色（内环主色、外细环第二色），名字牌加了签名色边框，小家谱里亮起的点填签名色。
- **设定表**：每张角色表加了「辨识」行，有 1/4 大小的黑剪影、同样大小的彩色人物、签名色色块和 hex。各表的引线、色板和“必须 / 不要”都按新设计改写了。
- **总排**：重新渲染，所有角色穿着自己的颜色并排站。每个名字上方加了签名色色条。
- **designbook.md**：新增 §0.2（假发规则、头饰尺寸、签名色表、短裙和长裙规则、相似的几对怎么分、出处）。§0 里的身高按新头饰更新；§2 加了说明：旧文和 §0.2 冲突的都作废；§6 改动记录和 §7 局限也已更新。
- **ep60 为什么不变**：`rig60.tsx` 只加了可选项（`netCol`、`stars`、`kiltCol`、`kiltCol2`、`hatArt`），不给时照原样画。

## 需要你知道 / 决定
1. **出处没有重查**：头饰的出处是按你给的方向写的（QV66 秃鹫冠、盖布的鹅 = 他名字的鹅形符号、“红亚麻夫人”），这次没有重新查博物馆记录，designbook 里写明了。
2. **我对两条要求的理解**：
   - **努特**：“plain black wig”我理解成不戴任何头饰，所以 nu 罐整个去掉了。
   - **阿努比斯**：“黑 + 金”我做成黑短裙 + 金腰带。
