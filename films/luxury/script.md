# 《你买的不是包》 · 剧本 v2 大纲（待审）

主人：主题还是奢侈品；"欲望"的心理学只用来解释每个现象。
主线：**跟着一只包走完它的一生**：工坊 → 精品店 → 你的手里 → 卖不掉的 / 假的。每到一站，揭一个行业真相，再用一个心理学实验解释"它为什么管用"。

| 段落 | 这一站（奢侈品真相） | 为什么管用（欲望的科学） | 画面 |
|---|---|---|---|
| 钩子 | 工坊：代工 53 欧元（米兰法院 2024） | | 一只通用款包从昏暗的工作台出发 |
| 标题 | 精品店：同一只包，2600 欧元 | 多出来的钱，买的是什么？ | 进入展柜，价格牌滚到 2600 |
| ① 门口 | 限流、排队 | 模仿欲望：我们想要别人想要的东西（基拉尔，一种解释） | 门外隔离带，一排影子 |
| ② 等待 | 等候名单、配货（诉讼指控）、"买不到" | 多巴胺管"想要"不管"喜欢"，最活跃在"快得到"之前（Berridge；Schultz） | 空展柜，一张写着"等候"的卡 |
| ③ 价格 | 年年涨价（来源待核） | 同一杯酒标 90 美元就更"好喝"，大脑也更愉悦（Plassmann 2008）；凡勃伦 | 价格牌越涨，灯越亮 |
| ④ 你手里（间奏） | 拿到以后 | 享乐适应：那股劲很快退去；觉得自己没分量时更想买（Rucker & Galinsky 2008） | 包放在家里桌上，灯慢慢变暗 |
| ⑤ 卖不掉的 | 宁可销毁也不打折：Burberry 2018 年销毁 2860 万英镑存货 | 打折会戳破"稀缺" | 卷帘门后的火光 |
| ⑥ 假的（渐强） | 全球假货 4670 亿美元（OECD–EUIPO 2025） | 大 logo 最常被仿，真有钱的人偏爱看不出牌子的款（Han 等 2010），于是形成信号军备竞赛 | 两只包在紫外灯下 |
| 揭晓（drop） | 53 和 2600 之间的差价 | 那是被设计出来的欲望 | 差价拆成：排队、等待、价格、logo |
| 三个问题 | 我想要的是它，还是"想要"的感觉？是我想要，还是别人想要？没有价格牌，它还好吗？ | | 卡片 |
| 回扣 | 包回到展柜，灯灭 | | |

# 《你买的不是包》 · 剧本 v1 大纲（待审）

主人：从心理学角度讲为什么想要奢侈品；卖家怎么制造购买欲；用真实数据揭露普通顾客不知道的真相；假货。

## 事实（待逐条核对）
- 迪奥代工 53 欧元 / 零售 2600 欧元：2024.6 米兰法院对 Dior Manufactures 实施司法托管的文件（The Fashion Law 转述路透社）。2025.3 托管提前解除，法院认可了整改。字幕必须写到这一点，以示公平。
- 阿玛尼：2024.4 米兰法院令，转包工人时薪 2–3 欧元（AFP）。
- Loro Piana：2025.7 米兰法院下令司法托管一年；品牌称已于 24 小时内终止与供应商的合作。
- Burberry：2018 财年销毁价值 2860 万英镑的存货（BoF）；同年宣布停止销毁（待核）。
- OECD–EUIPO 2025：全球假货贸易 4670 亿美元（占比、年份待核）。
- Rucker & Galinsky 2008, Journal of Consumer Research 35(2)。
- Han, Nunes & Drèze 2010, Journal of Marketing 74(4)。
- 香奈儿涨价幅度：需要可靠的价格史来源（品牌官方价或权威媒体）。
