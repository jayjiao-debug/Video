# 《打崩它》 · 剧本 v1（故事版，待审）

副标题（问句）：一个13岁的孩子，是怎么把俄罗斯方块打崩的？
一个故事：一堵"人类过不去"的墙，被一代代孩子用"换方法 + 立刻反馈 + 每次难一点"拆掉——就是心流和高效学习的配方，但讲成故事。
节奏：故事本身就是节奏——方块越掉越快，手指越按越快，音乐的 drop = 游戏崩溃的那一帧。
音乐：主人原曲不剪（标题 8.47 · 间奏 49.17 · 渐强 65.45 · drop 81.40），约 1:55 + 片尾卡。16:9，字幕 + BGM。
画面：全部代码绘制。方块用我们自己的金/深蓝画风（不还原原版游戏画面、不用任何商标）；手柄画成通用十字键；真人不画脸，只用名字卡。
