## 事实核对（写进片尾资料）

| 说法 | 依据 |
|---|---|
| 400 万倍太阳质量（与银河系中心黑洞相当） | 银心黑洞 Sgr A* 约 400 万倍太阳质量（EHT 2022） |
| 光被弯折，盘的背面出现在上方 | 史瓦西度规光线追踪（本片渲染器）；Luminet 1979 |
| 最内侧稳定轨道处气体速度约一半光速，靠近侧更亮 | 史瓦西 ISCO（6M）处局部轨道速度 0.5c；相对论多普勒增亮 |
| 小黑洞在视界外就会把人拉成面条，超大黑洞在视界处潮汐力可以忽略 | 潮汐加速度 ∝ M/r³：10 倍太阳质量的黑洞在视界处约 10⁸ m/s²·m⁻¹，400 万倍时约 10⁻³ |
| 远处看下落者变慢、变红、停在视界 | 引力时间延缓与红移（广义相对论标准结果） |
| 光子球在 1.5 倍视界半径（3M） | 史瓦西光子球 |
| 自由下落的人到视界时，黑影并不覆盖整片天空 | 下落相机的光行差（本片渲染器）；Hamilton, "Inside black holes" |
| 越过视界后仍能看到外面 | 外部的光继续落入视界 |
| 视界到中心不到半分钟 | 自无穷远静止下落：τ = 4GM/(3c³)，M = 4×10⁶ M☉ 时约 26 秒 |

## 待定 / 风险

- 视界以内的画面不做精确物理渲染（只做收暗和残光），字幕不对内部景象作具体断言。
- 抖音 360 规格（分辨率上限、元数据）上传前再核一次。
- 主题借《星际穿越》，但不画电影里的飞船、机器人、人物，不用电影配乐；标题不用"星际穿越"四字。
