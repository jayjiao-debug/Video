# 《对爸妈说“我爱你”，为什么这么难》 script v1 (~60–65 s, 17 lines)

Title options: ①《为什么说不出口》 ②《对爸妈说“我爱你”，为什么这么难》 ③《你高估了那份尴尬》
Night-friendly. Set idea: a dark bedroom lit only by a phone; memories appear as warm kitchen objects (cut fruit, a thermos, red envelope, long johns) drawn in code. No acted people.

## Hook
1. 你上一次对爸妈说“我爱你”，是什么时候？
2. 打出来，又删掉 — chat box: “妈，我爱你” typed, deleted → “妈，吃了吗”
3. 猜猜：如果说出口，爸妈会觉得？ — A 很尴尬 / B 很开心 / C 没感觉
→ TITLE

## Why it is hard
4. 中国家庭的爱，很少挂在嘴上
5. 一项研究里，15个华人孩子都说：爸妈的爱是“安静的”
6. 是切好的水果，是多打的生活费
7. 提到拥抱和“我爱你”的，只有4个
8. 我们没见过，所以不会说

## The twist
9. 芝加哥大学做过实验：让人给在乎的人写信
10. 写的人都以为，对方会很尴尬
11. 结果：对方比想的开心得多，也没那么尴尬
12. 答案是B：难开口，是你高估了尴尬
13. 说出来对你也好：连写三次爱意，胆固醇都降了

## Ending
14. 粗算一下：一年回家10天，爸妈50岁
15. 往后能见面的日子，大约300天
16. 说不出“我爱你”，就说“我想你了”
17. 现在就发，评论区说说他们回了什么
END CARD: 发给那个说不出口的自己
