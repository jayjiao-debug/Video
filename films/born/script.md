# 《你能出生，有多难》 script v1 (~90 s, 21 lines)

Title options: ①《你能出生，有多难》 ②《1万亿个祖先》 ③《你的家谱，缠成了一张网》
Look: an inverted family tree of light. One golden line from YOU to the top never breaks.

## Hook
1. 你有2个父母 — one gold point splits into 2
2. 4个祖父母，8个曾祖父母 — 4, 8
3. 每往上一代，翻一倍 — 16, 32, 64… the tree fans out
4. 猜猜：往上40代，你有多少个祖先位置？ — A 1000个 / B 100万个 / C 1万亿个
→ TITLE

## Climb
5. 按25年一代，40代大约是1000年前 — a timeline ruler: 今天 … 北宋
6. 2的40次方：约1.1万亿个位置 — counter rolls, tree becomes a glowing haze → C lights
7. 可从古到今，地球上一共只出生过约1170亿人 — a smaller sphere next to the haze
8. 1000年前，全世界只有约3亿人
9. 位置，比人还多 — the haze outgrows everything

## Twist
10. 答案是：很多位置，是同一个人 — branches bend and merge into knots
11. 同一个祖先，在你家谱里出现了很多次
12. 再往上几千年，所有人的家谱缠成一张网 — knots link into a net
13. 耶鲁大学2004年的模型说：几千年前活着的人
14. 要么是今天所有人的祖先，要么一个后代都没留下
15. 我们共享着，在长江边种稻子的祖先 — the net's top glows like a rice field by a river

## Survival
16. 而这张网上，通向你的那条线，一次都没断 — everything dims, one gold line remains
17. 历史上，大约一半孩子活不到成年 — each generation a fork: one branch fades
18. 每一代，你的祖先都是活下来的那一半
19. 熬过了饥荒、战乱、瘟疫
20. 只要有一个人，早走一步，就没有你

## Ending
21. 评论区：你知道的，最远的祖先是谁？
END CARD: 发给那个觉得自己很普通的人
