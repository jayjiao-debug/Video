# 《十四岁那年》 脚本 + 场景（v0，待审）

BGM 照常（不剪）：片头从第 16 拍起。8.1 s 第一个 drop → 金色标题；40.7 s 安静段；57.0 s 蓄力；72.9 s 大 drop（实测起音，拍子按它算）；约 122 s 结束。
数据：research/facts.md（网易云音乐官方账号每年的年度热歌榜；Spotify / Jakubowski 2020 / Krumhansl 2013）。

## 一、脚本（字幕，每行 ≤ 22 字，[金] = 关键词，{红} = 落空）

### 1. 开场（0–8 s）
- 你这辈子最常想起的歌，
- 大概率，是你[14岁]那年出的。
→ 8.1 s 金色标题卡《十四岁那年》

### 2. 证据（11.6–40.6 s）
- 2018年，一位数据科学家翻了Spotify的播放数据。
- 电台司令的《Creep》，1993年火遍全球。
- 在38岁的男人里，它排第164名——
- 他们1993年，正好[14岁]。
- 比他们大10岁、小10岁的人里，它{根本不上榜}。
- 2020年，一项研究给470人放了111首老歌：
- 最能勾起回忆的，是你[14岁]左右流行的那些。

### 3. 为什么是14岁（安静段，40.9–56.8 s）
- 为什么偏偏是14岁？
- 一种解释：不是那年的歌[更好听]，
- 是那年的你，正在经历一大堆"第一次"。
- 大脑把歌，和这些第一次[焊]在了一起。

### 4. 蓄力（57.0–72.8 s）
- 那你的14岁，是哪首歌？
- 我们翻了网易云音乐每一年的官方热歌榜。
- 找到你的出生年，[加14]——
- 准备好了。

### 6. 彩蛋 + 现在（97.5–113.8 s）
- 彩蛋：12年里，[薛之谦]有6年排进前二。
- 而2012年出生的你，[今年]刚好14岁。
- 你现在单曲循环的歌，就是以后[最常想起]的歌。
- 还有：你也会偏爱爸妈[14岁]时的歌。

### 7. 结尾（114–122 s）
- 片尾卡问题：你14岁那年，单曲循环的是哪首？（评论区：出生年 + 歌名）

## 二、场景

规则（上一集定下的）：镜头锁死、硬切；画面只有一个主角；固定的东西（出生年刻度条）挂在屏幕上，不放进场景；标注不动；字幕 68 px 黑体。

主角：**一个木头唱片箱**，里面竖着插满唱片套，一盏吊灯照着它。唱片套全部是我们自己设计的纯文字封套（年份、歌名、歌手），每一年一个颜色，不画任何真实专辑封面。

## 三、要你拍板的

1. 片名：《十四岁那年》，还是《你的14岁》？
2. 大 drop 每 4 拍翻一张，每张约 2 秒：第一名歌名读得完，第二第三名只能扫一眼。要不要改成每 8 拍一张（只放 6 年，片子更从容），还是保持 12 年全放？
3. 90 后要不要带上（网易云 2014 年才有年榜，带的话要换数据来源）？
