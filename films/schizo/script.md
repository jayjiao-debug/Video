# 《身体里的两个人》 script v1 (~2:00)

## Hook — the myth (0:00–0:16.6)
1. 一个人忽冷忽热，我们说他“精分”了 — a mirror, the reflection lags a beat behind
2. 电影里，精神分裂是：身体里住着两个人 — the reflection splits into two
3. 一个温柔，一个可怕
4. 可这，几乎全是误解 — the two reflections snap back into one, cracked
→ TITLE 《身体里的两个人》

## What splits (0:20–0:49)
5. “身体里有好几个人”，是另一种病：分离性身份障碍
6. 1908年，瑞士医生布洛伊勒造了“精神分裂”这个词
7. 希腊语里，schizo 是“分裂”，phren 是“心智”
8. 他说的分裂，是心智的各个部分，彼此脱节 — an orchestra: 看见、听见、思考、感受 each on its own stand
9. 看到的、听到的、想到的、感受到的，不再合拍 — the instruments drift off the beat
10. 全世界约2400万人，大约每300人中有1个
11. 在中国，终生患病率约0.7%
12. 常在青春期后期到成年早期开始

## The voices (break 0:49–1:05)
13. 最常见的，是听见别人听不到的声音 — an old radio picking up a station no one else hears
14. 对他们来说，这声音和真的一样
15. 斯坦福的人类学家，采访了三个城市的60位患者
16. 美国加州：声音大多刺耳、带威胁
17. 印度金奈：一半以上听到的是家人，像长辈在叮嘱
18. 加纳阿克拉：有一半人说，大多是好的声音
19. 同一种病，声音却带着各自文化的口音

## The name (build 1:05–1:22)
20. 名字本身，也会伤人
21. 2002年，日本把“精神分裂病”改名“统合失调症” — the orchestra sign repainted
22. 2014年，台湾改名“思觉失调症”
23. 改名后，日本报纸几乎不再用旧称
24. 可新闻标题里和犯罪有关的词，比例没变

## What it is (drop 1:22–1:48)
25. 它不是两个人格，也不是“疯”
26. 是大脑里，原本合拍的乐团，乱了节奏 — the drop: all instruments slam back onto the beat
27. 它可以治疗。越早发现，越容易把节奏调回来
28. 所以，下次别再随口说“我精分了”
29. 身体里没有两个人，只有一个人，在努力把世界调准
