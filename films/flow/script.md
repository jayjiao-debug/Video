# 《心流》 · 剧本 v4（巨星版，待审）

主人：用顶级运动员（詹姆斯、科比……）；不要一个人讲到底，而是用不同的比喻，同时故事要连贯。
主线（连贯性）：**一条隧道**。开头是塞纳说的"整条赛道变成了一条隧道"——之后每一位巨星的高光时刻，都是镜头穿过这条隧道到达的下一站；隧道本身就是"心流"。
结构：先让巨星们说"那是什么感觉"（都说不清）→ 心理学家说"说不清，但有规律"→ 用三个比喻（调频、开关、篮筐）讲规律 → drop 落在詹姆斯连得 25 分 → 回到观众自己。
画面：真人不画脸，只用名字卡（姓名、年份、那一场的数据）+ 球衣号码的大字；不出现球队标志。动作交给物件：球进网、比分牌跳字、赛车在隧道里穿行、粉末在灯光下散开。
音乐：主人原曲不剪（标题 8.47 · 间奏 49.17 · 渐强 65.45 · drop 81.40），约 2:00 + 片尾卡。
节奏：比分牌跳字不踩每一拍（越来越快、不规则）；隧道在渐强段加速；drop 落在"25"上。
