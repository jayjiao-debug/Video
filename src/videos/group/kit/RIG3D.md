# 立体角色 rig3d

手绘感的立体角色：`src/videos/group/kit/rig3d.ts`。按参考视频的画法做的（一团不规则的头上贴一张 2D 的脸，衣服包在身体上，头发画在头上，细的四肢，毛笔粗细的描边），和纸片角色 `kit/cast.ts` 用同一套 Look、同一个 CastLight，表情名字和 `toon.ts` 的 `Expr` 一样。

2026-11-10 做，依据是两张参考截图和 11 条参考视频里随机抽的 198 帧。对比图、动态对比和抽帧研究不在仓库里（里面有参考视频的画面），在项目共享文件夹 `character-3d-look/ours/`。

## 这是什么

参考博主的角色做法在我们自己管线里的实现：`src/videos/group/kit/rig3d.ts`（角色本体）和 `kit/rigacc/`（角色道具，见下面“角色道具”）。
它和现在的纸片角色 `kit/cast.ts` 用同一套 Look（YOU、RESEARCHER、classmate(seed)）、同一个 CastLight（例如 LAB_CAST_LIGHT），接口也基本一样（`set` / `handWorld` / `update`），表情的名字和 `toon.ts` 的 `Expr` 一样，所以旧镜头里的表情可以直接换过来。

全部是代码画的：头、五官、头发、帽子、描边、明暗都在这个文件里，每个角色的不规则按固定的种子算。同样的输入每次出来的画面一样，渲染时没有任何模型参与。以后的片子只要“用”这个文件，画风就不会变；要改画风才需要动它。

## 参考的五官是怎么画的（在 198 帧随机抽帧里放大 60 多个头量的）

单位 u 是头的填色宽度的 1%。

1. 所有线条是同一支圆头笔，粗约 3.0 到 3.3u。旧版的眉毛和眼睛是粗的楔形，这是最大的差别。
2. 两眼在中线两侧各约 14u。默认的眼睛是一条约 20u 的眼皮线，下面挂半个圆瞳孔。其他眼睛：竖的圆点（约 10 × 13u）、圆圈眼（约 24u，里面一个小瞳孔）、笑眼弧线（约 18 × 8u）、一条平线、“＞ ＜”。
3. 眉毛是简单的弧线，长约 18u，离眼皮线约 12u，常常一高一低。
4. 嘴在眼线下面约 19u，很小：默认是一个约 10 × 4u 的小扁嘴；微笑是约 17u 的弧线；大笑是约 40 × 13u 的张嘴，里面一排分开的牙；龇牙是一个约 26 × 17u 的圆角框，画成牙格；还有小圆嘴和波浪嘴。
5. 情绪符号：汗滴、脸红、怒气符号、速度线。
6. 戴眼镜的人，镜片本身就是眼眶，里面只画瞳孔。
7. 头发是平涂加描边：发际线有一条墨线，有分缝，有几条浅色发丝，刘海压得很低。

## 参考的手绘感从哪来（在长椅那帧上量的，第三版）

1. 头不是正圆，是略扁、不对称的一团，宽大约是高的 1.1 到 1.2 倍。
2. 描边有粗细：受光一侧约为头宽的 2%，背光一侧约 5%，下巴下面约 8%。身体的线和头的线一样重。
3. 颜色平涂，明暗是画上去的：
   - 头：白底，沿背光一侧和下缘有一条淡紫色带，宽约头宽的 7%，边缘是软的。
   - 衣服：受光一侧约 15% 宽是一条浅色边，中间一半完全平涂，背光一侧约 30% 渐渐变暗（偏冷）。
   - 四肢：接近墨色的平涂，受光一侧靠里有一条平的浅色带，宽约肢体的四分之一。
4. 头完整地画在身体前面，下巴的线压住衣领。
5. 比例：头约占身高三分之一；头圈以下看得见的身体宽约 0.57 个头宽、长约 0.8 个头宽；腿约 1.18 个头宽；手臂约 0.8 个头宽。

只凭截图分不出参考是 2D 画贴在卡片上，还是处理过的 3D 模型，两种都说得通。

## 我们怎么做到的

`RigCast` 有一个 `hand` 参数：0 是干净的几何体，1 是参考那种手绘程度（默认）。

- 五官：一张平的 2D 画，按上面那套零件画，23 个表情。它按位置贴在头上（不跟着头的起伏弯曲），按远近缩放（任何镜头距离下在头上一样大），画在头发上面（挑起的眉毛可以压过刘海），只有帽子能盖住它。每个角色的眼睛大小和左右略有不同，按种子固定。
- 眨眼只有两格（半闭、全闭），没有中间帧。视线 `gaze` 以 0.5 为一档，瞳孔在眼皮线下面滑动。
- 头发直接画在头上（同一个面，发际线不会有两个面打架的亮点）：平涂、发际线墨线、分缝、几条浅色发丝，刘海压低。线是着色器里算的，细到不足一个像素之前先淡出。
- 帽子：鸭舌帽有画出来的缝线和一圈压线，毛线帽有罗纹。帽子下面的头发只从鬓角往后露出来。帽檐是从帽圈下面长出来的一块楔形，不碰头，没有外壳描边，墨线直接画在帽檐边上。帽子先画，头让开帽子占的像素。
- 形状不规则：头用 Look 里已有的头形再加一点起伏；身体两侧略有起伏；四肢微弯、粗细略变；脸和衣服的图案整体轻微扭一下。
- 描边像毛笔：朝光一侧细，背光一侧和下面粗，沿线还有缓慢的粗细变化。
- 明暗是画的，不是算的：没有真实光照的渐变，只有量出来的那几条带子。
- 帽子、头发和道具是“横着过形体”上色的，和衣服一样：朝光的一侧有一条亮带，中间平涂，背光的三分之一压暗（见“帽子、头发和道具上的光”）。镜头绕着转时亮带始终在光的那一侧，这是它们看起来有体积的原因。
- 头的受光一侧，轮廓里面有一条暖色的细弧线；宽帽檐在额头上投一条影子。
- 头压在自己的身体和四肢上面，但对别的角色、道具、布景保持真实的前后关系（用模板缓冲做的，见“接入正片”）。
- 所有不规则都按角色的种子固定，跟着部件走，不逐帧变化。没有“线条抖动”这种效果，是为了守住不闪烁的规矩。

## 运动规则

1. 脸的方向离镜头最多 12°（`FACE_MAX`），只朝人物面对的一侧挪一点。不出侧脸。
2. 身体朝镜头转，离镜头最多 45°（`BODY_MAX`）。衣服是包在身体上的一张图，镜头一动自己就有透视。
3. 头发和帽子跟身体转，脸几乎不动，两者错开是立体感的主要来源。
4. 两个坐标系：行进系（脚、步幅、拉绳的后仰，钉在世界里，镜头或身体转动时脚不滑）和展示系（朝镜头转的躯干、手臂、头）。
5. 背面：人物朝向离镜头超过约 115° 后连续过渡到真正的背面，脸到头的边缘时淡出。也可以用 `state.turn`（0 到 1）手动控制，建议用 8 到 12 帧做转身。
6. 手臂有净空求解：肘部绕肩到手的轴转动，直到整条手臂连同描边都不碰身体。个别体型在肩膀下面还是贴到身体时，整条手臂往外让，一次 1 毫米，最多 8 毫米（只对没有钉在世界里的手）。每帧可以读 `rig.qa.clear`（小于 0 就是穿模）和 `rig.qa.reach`（大于 0 就是够不着）。
7. 描边最细不小于 1.6 像素，远景里细线不会闪。

## 说话和头部动作

参考是怎么做的（在 Cashiers、Roller Coasters、Grave Bell 等片段上逐帧量的。嘴型这一项只量过一轮，没有第二个人复核）：

- 说话有一套专用的嘴，6 到 8 个，是静止时那张嘴的 2 到 4 倍大：闭合线 26×4.6u、扁条 38×9、露牙条 40×13、小开口 28×13（有舌头）、半开 36×19（上下两排牙加舌头）、大开 36×26、圆口 24×22、吐舌 40×14（u 是头宽的 1%）。嘴挂在上唇上：上沿最多抬 5u，往下张，离下巴留 6 到 7u。
- 节奏：一个音节一开一合（5 到 6 帧），每 1.2 到 1.6 帧换一张画，比声音早 1 到 3 帧张嘴，句末用 8 到 9 帧收住。只有角色自己说台词时嘴才动，旁白说话时不动。
- 头跟着说话动，都是短促的一下，没有持续的晃动：重音上头放大 6% 到 7%，约 3 帧；落下时压扁约 10%，再拉长约 5%；一句话歪一次头，几度；大笑时每 6 到 7 帧前后晃一次（约 0.056 个头半径、2°）；眨眼落在句子的接缝上；脸滑到一侧时变窄 13%。

我们的做法：

```ts
import { rigSpeak, rigSay, rigSayEnv, rigHeadAccent, rigHeadAdd, type RigLine } from "../kit/rig3d";

// 一句台词：from、to 是秒；syl 是音节数（中文就是字数，不写就按每秒 5.5 个）；stress 是第几个字重读（从 0 数）
const lines: RigLine[] = [{ from: 0.3, to: 1.5, syl: 6, stress: [1] }, { from: 2.0, to: 3.4, syl: 7, stress: [0, 4] }];
const sp = rigSpeak(t, lines, id);            // t = 这一镜里的秒数；id = 角色的序号，每个人的嘴型顺序不同
a.set({ ..., mouth: sp.mouth, head: sp.head, blink: sp.blink ?? 平时的眨眼 });
```

- `rigSpeak` 一次给出三样：嘴（一个音节一开一合，重读的字用大开口，提前 2 帧张嘴，句末 8 帧收住）、头（每句开头点一下、朝一侧歪过去，重读的字上弹大一下）、眨眼（每句开始前和结束后各一次）。
- 只要嘴：`rigSay(t, lines)`。有配音时按音量走：`rigSayEnv(帧号, 每帧音量的数组)`，音量 0 到 1，四档开口。
- `state.mouth` 可以直接给：`line`、`pill`、`strip`、`small`、`half`、`wide`、`round`、`tongue`（`RIG_MOUTHS`）；不给就是表情自己的嘴。说话的嘴跟着表情的情绪弯：笑着说嘴角上翘，皱眉说嘴角下压。嘴在胡子下面会自动放低。
- `state.head`（`RigHead`）是头自己的一层，叠在姿势上面：`dx`、`dy`（往画面右、往上，单位是头半径）、`tilt`（度，正数是头顶朝画面右，绕下巴转）、`scale`（放大，从下巴往上长）、`squash`（压扁这么多、同时变宽一半；负数是拉长）。脸、头发、帽子、耳机都跟着。
- 现成的头部动作：`rigHeadAccent(kind, 从动作开始算的秒数)`，`kind` 是 `pop`（弹大）、`squash`（压扁再拉长）、`nod`（点头）、`jolt`（一惊）、`shake`（摇头）、`laugh`（笑得前后晃，`{ dur }` 给时长）、`lean`（歪过去停住）。动作结束后返回 `undefined`。几个动作叠在一起用 `rigHeadAdd(a, b, ...)`。
- 说话的嘴是脸那张画的一部分，所以和五官一样有缓存（160 张），不会每帧重画。
- 规矩：旁白说话时不要给角色动嘴。参考从不这样做。

## 走路

参考的走路（Second Draw 21.67 到 23.0 秒，每 10.5 帧一步）是弹着走的：脚落地后 0 到 1 帧，整个人急速沉到最低点，然后慢慢升到两腿交错时的最高点，幅度是身高的 7% 到 9%；头和帽子在最低点之后 1 到 2 帧往前点 11° 到 15°，到最高点时已经回正；身体每一步往前晃一下；脚踩在地上不滑。

```ts
import { rigWalk } from "../kit/rig3d";
a.set({ at, facing, pose: rigWalk(走过的距离, 速度) });      // 米、米每秒；匀速
```

- `rigWalk` 按速度定步子的长短，让步频接近参考（大约 11 帧一步）：走得慢是小碎步，走得快步子大（半步 0.1 到 0.27 米），脚始终踩实。弹跳的幅度跟着步子走，小步弹得少。第三个参数是弹跳的多少（1 是默认，0 是平移）。
- 速度在一镜里会变的话，自己算相位：`pose: { kind: "walk", phase, stride }`，`phase` 是按步幅累计的圈数。
- 身体的高低是这样定的：两腿交错时支撑腿伸直（比站着高 3 厘米，站着时腿略微有余量），最低点比它低 9 厘米（身高的 6%），膝盖弯但不蹲。数值在 `rig3d.ts` 的 `WALK`。

## 帽子、头发和道具上的光

参考是怎么做的（圆顶礼帽在一段镜头环绕里量的，头发量了七个头）：

- 帽子：帽冠朝光的 20% 到 29% 是一条亮带（屏幕亮度约 112），很快落到中间的 62，背光的三分之一再降到 38。镜头绕着转，亮带一直在光的那一侧。另外有一条手画的高光细线，帽檐用两条线画。
- 头发：5 到 8 根顺着发流的浅色梳线、一条分缝、一个渐变（受光侧是中间的 1.2 倍，背光侧 0.75 倍）。
- 宽帽檐在上半张脸投一条偏蓝的软边影子。
- 头的受光一侧，轮廓里面有一条暖色的细弧线，头发上也有。
- 场景里的光会落在角色身上（光柱、灯的暖色、整体的色调）。

我们的做法（都在着色器里，数值在 `rig3d.ts` 的 `PART`、`RIM`、`BRIM_ELEV`）：

- 道具和帽子（`PART.prop`）：亮带、中间平涂、背光的三分之一压暗。浅色的东西（白色厨师帽）暗面走淡紫色而不是变灰。
- 头发（画在头上的和立体的发团）：五根梳线，受光侧提亮，背光侧压暗。卷发的九个发卷按整个头的形状受光（`rigMat` 的 `form`），和画在头上的头发连成一片，不是一粒一个亮面；丸子头和马尾离开头，各自受光。
- 帽檐的影子：用 `b.brim(...)` 做的帽檐自动投影；自己建形状的帽子写一行 `b.shadow({ y, r, rSide, from, to })`（帽檐边缘的高度、正面和两侧伸出多远，单位是头半径；`from`、`to` 是只有前面一段的帽舌的角度范围）。影子是帽檐下面的一条带子，帽檐伸出多远它就多深，不随镜头变，所以镜头转的时候不会游动。帽檐不比头宽的帽子（礼帽、圆顶帽）不投影。
- 受光侧的暖色弧线：每个头都有，细到不足一个像素之前先淡出。
- 场景里的光落在角色身上：还没有做。

## 用法

```ts
const rc = new RigCast(scene, { light: LAB_CAST_LIGHT });          // 可加 hand: 0..1
const a = rc.add(YOU);                                   // 或 rc.add(look, { hat: { kind: "cap", col: "#3f6b8f" } })
// 每帧：
a.set({ at, facing, pose: { kind: "haul", t, amount: 0.85 }, hands: [worldA, worldB], twist: 0.75, expr: "huff", blink, gaze });
rc.update(camera, renderHeightPx);
rope.update({ a: a.handWorld(1), ... });                 // 绳子等在 update 之后取手的位置
```

- 表情（`RIG_EXPRS`）：neutral、smile、happy、grin、laugh、smile_closed、relief、relief_open、smug、deadpan、focus、stern、huff、sad、sigh、nervous、shock、dazed、pained、wince、whistle、lick、sleep。
- `state.blink`：0 睁开、0.5 半闭、1 闭上。`state.gaze`：-1（画面左）到 1（画面右），0.5 一档。
- `rigFaceCanvas(look, expr, { lid, gaze, brim })`：单独拿一张脸的画（出表情表、检查用）。
- 已有姿势：`idle`、`walk`（见“走路”）、`wave`、`point`、`haul`、`hold`（拿板子）、`cheer`；坐着的 `sit` / `desk`、`write`（写字）和 `phone`（看手机、打电话），连同 `state.seat`（坐在哪）见 `RIG3D_poses.md`。
- 说话和头部动作：`state.mouth`、`state.head`（见“说话和头部动作”）。
- 表情的名字写错会直接报错，报错里列出全部名字。
- `state.twist`：躯干相对脚的朝向自己再转多少（弧度，正数朝人物的左边）。手臂短（0.84 个头宽），身体不转的话够不到身侧的绳子，所以拉绳的人要朝绳子转。
- `state.headFront`：默认 1，头压在自己的身体上面；0 是按真实前后关系画。
- 人物自己的手不会画在自己的头前面，所以挥手、欢呼的手摆在头的旁边或下面。例外是 `phone` 姿势和 `state.armFront`：那条手臂按真实的前后关系画，并且保证在头的外面（见 `RIG3D_poses.md`）。
- 镜头规则：不要让人物朝向停在离镜头 115° 到 170° 之间（那是转身过渡区）；要背面就用 `turn = 1`；用后仰和前倾表现用力，不拉伸头。

## 角色道具

眼镜、胡子、帽子、耳机、领带、白大褂、书包、公文包这类一眼说明“这是谁”的东西。每个道具是 `src/videos/group/kit/rigacc/` 里的一个小文件，装到角色上只要一行，**加新道具不用改 `rig3d.ts`**。

```ts
import { accessories } from "../kit/rigacc/catalog";
import { topHat, glasses } from "../kit/rigacc";

const boss = rc.add(look, { acc: accessories("topHat", "moustache.handlebar", "suit", "briefcase") });   // 按名字取
const prof = rc.add(look, { acc: [glasses({ kind: "square" }), topHat({ col: "#5a3b2a", tilt: 12 })] }); // 或者自己调颜色
```

### 位置

每个道具写明自己占哪些位置：`eyes`（眼睛）、`lip`（上唇）、`chin`、`mouth`、`cheek`、`hat`、`crown`（头顶）、`ears`、`neck`、`coat`（外套）、`chest`、`waist`、`back`、`shoulder`、`hand0`（右手）、`hand1`（左手）。

### 做道具时要守的几条

写在 `rig3d.ts` 的 `Acc`、`FaceKit`、`OutfitKit`、`PartKit` 这几个类型的注释里，这里是大意：

- **画在脸上**（`face`，或者要垫在五官下面的用 `faceUnder`）：和五官是同一张画，单位是头宽的 1%，表情怎么换都跟着。镜片会自动把眼距拉开一点。
- **画在衣服上**（`outfit`）：画在包住身体的那张图上，用“绕身体多少度、多高”定位，镜头一转自己就有透视。
- **包住头的**用 `shell`（一片开口的壳：先画，头让开它占的像素，所以不会和头打架）。**有厚度的**用 `solid`（自带描边）。**薄片**用 `plate`（描边画在片的边上；薄片如果用外壳描边，侧看会变成一条发丝线或一串点，会闪）。
- **帽子**要写明帽圈的位置和头发怎么处理：`hair: "cut"` 是压低戴，刘海去掉，头发只从鬓角往后露；`hair: "keep"` 是顶在头上，头发不动。
- **头上的东西不用管手臂**（头永远画在自己手臂前面）。**身上的东西**要用 `keepOut` 告诉手臂绕开哪里。**手里的东西**用 `held`，跟着那只手走。
- **大的平面（帽檐）的描边只在边缘出。** `b.brim` 自己会处理。自己建形状的帽檐（`cowboyhat.ts`）用 `sunkHull(几何, up)` 告诉底层每个点出不出描边：边缘那一圈写 1，平面上写 0。原因见“单像素点”第 4 条。
- **贴在壳外面的带子**（安全帽的棱）要把两条长边收进壳里：`b.band({ edge })`。悬着的带子侧看时底下会透出背景。
- 贴图的缓存名要包含所有会改变画面的参数（颜色、款式），不然两个颜色不同的会共用一张图。
- 不用随机数，不逐帧变化。所有不规则都按角色的种子固定，这是不闪烁的前提。

### 规则（rules）

三条规则由 `acc_check.py` 自动查，每个道具在 13 种体型上都要守住：

1. **脸前面不放立体的东西**（规则名 `face`）。脸是一张朝镜头转的画，头和头上的东西跟身体转，两者最多错开 24°。所以一个立体的零件只要在脸的正面 62° 以内、眉毛以下、又在皮肤外面（`FACE_ZONE`），总有某个机位会压到眼睛或嘴，或者离开它本来该在的嘴边。属于那里的东西要画在脸上（`Acc.face`）：耳麦的话筒、口罩、胡子都是这样做的。
2. **手里的东西不能穿过自己的身体和头**（`held`，容差 3 毫米）。位置用 `held({ offset })` 调；如果东西是垂着拿的（公文包、桶），写 `hang: true`，那只手就一直垂着，挥手和指交给另一只手。
3. **不能让手臂多出穿模或够不着的情况**：和不带道具的同一个人逐个情况比。

另外，帽子有帽檐就该在头上投影：用 `b.brim` 会自动有，自己建形状的写 `b.shadow`（见“帽子、头发和道具上的光”）。

### 怎么保证加了新的不会弄坏旧的

1. **没装道具的角色走的还是原来那条路。** `scripts/rig3d/regress.py` 把 43 张基准画面（16 组镜头、6 种发型、两种旧帽子）重出一遍，和记录下来的逐像素比对，差一个像素都会报。把接口改成可插拔的那次改动就是这么验证的：43 张全部相同。
2. **每个道具有自己的基准画面**（正面、侧面、背面各一张）。新加一个道具只会多出它自己的三张；如果动到了别的道具或者角色本体，对应的画面会被点名，还会生成一张“原来 | 现在 | 差别”的对比图。
3. **位置冲突直接报错**，不会悄悄叠在一起。
4. **清单里的每个道具都会自动进穿模检查**：13 种体型、5 个姿势、32 个机位，共一万多种情况，逐个和不带道具的同一个人比，只要有一种情况因为道具而穿模就报。
5. **运动检查**：每个道具戴在一个人身上，原地转身 21 帧、走一个步子循环 16 帧，大小和正片的全身镜头一样，数单像素点（见“单像素点”），和不戴它的同一个人比。静止的图查不出这一类问题。
6. 着色器编译失败会让出图直接报错（以前是照常出图，只是头变成一个黑球）。
7. 一条命令 `python3 scripts/rig3d/acc_check.py` 把上面这些全跑一遍，一共六步；`--fast` 只跑不出图的几步（类型、手臂、清单、姿势），约 6 分钟。第 6 步查坐姿和打电话：13 种体型、4 种座位、16 个机位，头不动和做重音动作各一遍，手里有手机或笔，头上有耳机或帽子，任何东西都不能穿过身体、头、椅子和桌子（见 `RIG3D_poses.md`）。

## 单像素点（specks）

是什么：角色身上孤零零的一个像素颜色不对，只出现一两帧，人转身或镜头移动时一闪。静止的图上查不出来，要在一段运动的画面里数。

原因：预览和渲染农场用的都是软件渲染器（SwiftShader）。几乎侧对镜头的细三角形，它的深度算不准：顶点先对齐到十六分之一像素，在一条细缝上这点误差相当于几厘米的深度。于是这个三角形的某一个采样点比它真实的位置靠前，落在正好站在它前面的东西上：头边上的耳机、腿前面的公文包、公文包上的扣子。

底层的四个办法（都在 `rig3d.ts`，对所有角色和道具生效，不是修某一个道具）：

1. `SLOPE_BIAS = 1`：每个三角形按自己的深度斜率往后退一个像素的量。正对镜头的面不动；侧对镜头的细缝退后的量大约等于它可能算错的量，所以只在它确实靠前很多的地方才露出来。不丢三角形，轮廓不变。
2. 头的皮肤在模板缓冲里做记号（`SKIN_BIT`），皮肤自己的描边跳过这些像素。没有这一步，`SLOPE_BIAS` 会让皮肤最外一圈退到自己的描边后面，轮廓随着转头忽大忽小零点几个像素。
3. 脚不用 `SLOPE_BIAS`：脚贴着地板，地板不是角色的材质、不会跟着后退，脚最低的那条边会被地板透出一两个像素。

4. 大平面的描边只在边缘鼓出来（`sunkHull`，`b.brim` 自带）。这是 `SLOPE_BIAS` 的副作用引出来的：一个面越接近侧对镜头，被往后推得越远，相邻两个三角形推的量还不一样。帽檐上下两个大平面的描边，原来是整张平面往外推一个线宽。镜头和帽檐差不多平的时候（镜头在头的高度附近，走路点头时每一步都会经过），这张平面正好侧对镜头，它就是帽檐边上那条线，于是被一格一格地推到帽身后面：线里出现一排帽带颜色的点，一步闪一下。现在平面部分的描边埋在帽檐里面，只有最外一圈鼓出来，帽檐边上的线由这一圈又短又陡的面画出来，没有哪个机位会侧对它。

备用的办法 `EDGE_ON`（把几乎侧对镜头的三角形整个不画）也能去掉这些点，但轮廓的边会随转身移动零点几个像素，所以默认关着。

试过、没用的办法：给 `SLOPE_BIAS` 的后退量加上限（`EXT_polygon_offset_clamp`，上限 5、12、30 毫米各试了一次）。耳机上的点从 4 个回到 30 到 47 个，帽子上的点也没少：深度算错的量没有上限，后退量也就不能有。

做道具时怎么避免：零件要么明显在别的东西外面，要么深深埋在里面，不要刚好贴着表面（差几毫米的两层会互相透出单个像素）；薄片用 `plate` 不用 `solid`；藏起来的端头埋进头或别的零件里面。

怎么数：`python3 scripts/rig3d/specks.py <帧目录> [阈值] [--mask <遮罩帧目录>]`。镜头在动的时候，布景自己的细线（瓷砖缝、百叶窗）也会一个像素一个像素地出没，那不是角色的问题。所以镜头在动的片段要带 `--mask`：同一段再出一遍只有角色的图（预览参数加 `"mask": true`，角色在品红底上，没有布景和后期），只数角色身上和紧挨角色一个像素以内的点。`acc_check.py` 的运动检查用的是同一个数法：一排五个人，每个道具和站在同一个位置、不戴它的同一个人比，多出 3 个以上才报。3 个以内的是细线和高光尖端上很淡的点（同一个道具站在一排里的不同位置，会有 0 到 3 个的出入）；描边断成一排点的那种问题，一次会多出 10 个以上。不戴道具的人站在同一个位置，每次跑出来的数是一样的。

## 怎么出图（在仓库根目录）

需要：`npm ci` 装好依赖；带 Chromium 的 Playwright（Claude 的云端环境里自带）；`ffmpeg`；Python 的 numpy 和 Pillow。

1. 单帧：`bash scripts/rig3d/shot.sh src/videos/group/preview/rig3d_trio_rig.ts out.png`，大约 10 秒（84 人那张约 30 秒）。
2. 多帧：`bash scripts/rig3d/frames.sh src/videos/group/preview/rig3d_orbit720_rig.ts outdir 120 720 1280`。只出其中几帧：`bash scripts/rig3d/pick.sh <入口> outdir 540 960 4 6 40`。
3. 23 个表情：`bash scripts/rig3d/frames.sh src/videos/group/preview/rig3d_exprs_rig.ts outdir 23 480 480`。
4. 类型检查：`npx tsc -p scripts/rig3d/tsconfig.rig.json`，`n8ao` 的 TS7016 报错可以忽略。
5. 闪烁扫描：把帧合成 mp4 后 `python3 scripts/rig3d/scan.py clip.mp4 outdir 帧数`。
6. 逐像素闪点：`python3 scripts/rig3d/sparkle.py <帧目录> [对照帧目录]`。单像素孤点：`python3 scripts/rig3d/specks.py <帧目录> [阈值] [--mask <遮罩帧目录>]`（见“单像素点”）。
7. 放大检查：`preview/rig3d_capbig_rig.ts` 是戴帽转身的 2160×3840 版本，配合 `pick.sh` 出单帧。

8. 回归检查：`python3 scripts/rig3d/regress.py`。改了 `rig3d.ts`、`kit/rigacc/` 或预览之后跑，所有基准画面逐像素比对，约 3 分钟；只跑一部分：`python3 scripts/rig3d/regress.py trio turn_ acc_topHat`。画面是有意改的，先看图再 `--update` 记录新的基准。换了机器或浏览器版本，哈希可能全部不同：先在没改动的分支上 `--update` 一次，再改再比。
9. 道具检查：`python3 scripts/rig3d/acc_check.py`（见“角色道具”）。

10. 运动测试（镜头边绕边推，人在走、在说话、在做头部动作）：入口 `preview/rig3d_acc_row.ts`，参数全在 `--opts` 里。`lineup.who` 里每个人可以写 `go`（每秒走多少米，脚和地面对得上）、`talk`（按 `rigSpeak` 说话）、`act`（重复一个头部动作：`pop`、`squash`、`nod`、`shake`、`laugh` 等）、`mouth`（固定一个说话嘴型，出嘴型表用）、`at`（站在哪）；`lineup.run` 是姿势自己的时间每秒走多少帧；`orbit` 的 `r1`、`y1`、`look1`、`near1` 是最后一帧的值，写了就是边绕边推；`mask` 出只有角色的图。镜头退到墙外时要给 `near`。

`render.mjs` 可以从命令行改预览的参数，一个入口出很多种图：`node scripts/rig3d/render.mjs <入口.ts> <out.png 或目录> [--frames N | --pick 0,20,40] [--size 540x960] [--opts '{"turn":{"look":"friend3"}}']`。

预览每帧会在控制台打印 `QA: frame N reach X clear Y`（第 0 帧，以及任何 reach 大于 0.012 或 clear 小于 -0.0005 的帧）。

## 接入正片还要做的事

- **模板缓冲**：正片的 `Film.tsx` 里 `<EffectComposer multisampling={4}>` 要加上 `stencilBuffer`。没有它，头压不住自己的身体，下巴的线会被衣领切掉，帽子也压不住头。角色分三步画（`renderOrder` 0、1、2，帽子和头在 0 之前），每帧开头自己清模板。正片还有描边、景深、泛光、调色几道后期，预览里没有，接入后要在正片的一帧上再查一次。
- 《为什么总有人划水》用到的姿势里，`desk`（坐在课桌前）、`write`、`phone` 已经有了（见 `RIG3D_poses.md`）；还没有的是 `reach`、`curl`、`sitUp`。纸片角色另有 `jog`、`lookDown`、`dragged`、`throw`、`cardUp`、`dust`。
- 手在脸前面的姿势：打电话已经有了（`state.armFront` 这个开关让一条手臂画在自己的头前面）；捂脸这类还没有做成姿势，可以用 `armFront` 加 `hands` 自己摆。
- 角色只投影、不受影（见上表第一项）。
- 和布景的防穿模：坐着时对自己的椅子和桌子有了（`state.seat`）；别的布景（床、柜子、别人）还没有。
- 描边经过后期（环境光遮蔽）之后比参考更黑：屏幕上约 (8, 4, 19)，参考约 (32, 26, 46)。把描边颜色提亮可以解决，但提亮后环境光遮蔽的噪点可能在线上闪，所以没动。

1. 镜片里的圆圈眼成了双圈：改成镜片就是眼眶。
2. 视线移动太小看不出来：加大到 3.6u。
3. 帽圈和帽檐之间有一条白缝，额头上有一条一像素的细线，帽檐下有碎点：都来自帽檐的外壳描边。薄片的外壳描边在侧对镜头时会变成发丝线或一排点，所以帽檐不再用外壳描边，改成楔形，墨线画在上面。
4. 帽子下面的刘海从帽圈边上露出一条：帽子下面的头发改成只从鬓角往后露。
5. 帽子上偶尔有一个像素的浅色点：头的轮廓在帽子下面，渲染器给侧对镜头的三角形的某一个采样点算错了深度，头的颜色就透到帽子上。改成帽子先画、头让开帽子的像素。放大到 2160×3840 的那一帧上原来有 3 个点，现在是 0。
6. 着色器里一个变量声明了两次，编译失败，头成了黑球，而出图照常“成功”。现在着色器编译失败会让出图直接报错。
7. 歪头时手臂跟着动了 2 毫米：帽檐影子和歪头的两段代码借用了公共的临时变量，而后面手臂的计算还要用它。改成各用各的。这是 `acc_check.py --fast` 的手臂那一步抓到的，图上看不出来。
8. 镜头在动时，数单像素点的脚本把布景的瓷砖缝也数了进去（两段里数出 204 和 164 个，没有一个在角色身上）。加了遮罩，只数角色身上的。
9. 表情的名字写错时，出图在很后面才以一句看不懂的话失败。现在直接报错，并列出全部名字。
10. 走路像在一下一下地蹲：步子短、起伏大、两腿交错时没有站直。改成步子的长短跟着速度、交错时支撑腿伸直、最低点比它低 9 厘米。
11. 帽檐的影子成了一侧太阳穴上的一个楔形：布景的主光又低又偏。改成画出来的一盏灯，高度限制在 42° 到 60° 之间，朝主光那边偏一点。
12. 卷发在新的光下成了一粒一粒的小球，每粒各有一个亮面和一个暗面，从背后看是一圈深色的三角。改成发卷按整个头的形状受光（`rigMat` 的 `form`），和画在头上的头发连成一片。这是重录回归图时逐张看出来的。
13. 礼帽、圆顶礼帽、安全帽、牛仔帽在转身和走路点头时，帽檐边上的描边里出一排单像素点，一步闪一下。这是 `acc_check.py` 的运动检查抓到的，静止的图上没有。原因和修法见“单像素点”第 4 条：改的是所有帽檐共用的描边做法，不是逐顶帽子修。同一排六个人的 37 帧测试里，四顶帽子身上的点从 42 个（礼帽 8、圆顶礼帽 1、安全帽 21、牛仔帽 12） 变成 4 个（0、0、2、2）。副作用见“已知的小问题”第二条。
14. 安全帽帽顶的棱是悬在帽壳外面的一条带子，转过头时底下透出背景，帽顶有一小团乱点。改成两条长边埋进帽壳的一条棱（`b.band` 的 `edge`）。

## 已知的小问题

- **人多、带道具、镜头在动的时候，角色身上有只出现一帧的单像素点。** 五段测试片里一共 204 个（平均三帧一个），数目见上表；和周围差 55 以上（满分 255）的有 35 个，其余更淡。没有一个在脸或皮肤上。放大看，它们都出在很细的东西上：手臂和腿上那条高光线的起点；两条手脚、或者头梁和描边挨得很近时中间剩下的一条细缝；几条描边交汇的地方（帽带接帽檐）；道具上的细线（耳机罩的圈、礼帽帽带的边、圆顶礼帽帽檐下沿、大檐帽帽舌根部、厨师帽的褶）。其中帽檐边上的那一类后来查清并修掉了（检查记录第 13 条），这里的数是修之前的。其余的，判断原因是这些细条不足一个像素宽，画出来就断成了点（没有逐个证实）。`acc_check.py` 的运动检查里，礼帽和耳机各比不戴时多 3 个这样的点（帽檐两头高光的尖、耳机罩和头梁上画的细线），正好在上限上；其余 24 个道具多 0 到 2 个。它们不是修掉的那种深度误差的黑点（见“单像素点”）：那种点落在皮肤上、成片出现，这种是零星的、颜色接近周围。正片的画面比测试片宽 1.5 倍，细条也宽 1.5 倍，会少一些。要彻底去掉，得把这些细线画粗一点、让高光线淡出而不是变细，或者出图时放大一倍再缩小（出图时间约四倍）。
- **帽檐边缘的里侧多一条线。** 这是第 13 条的修法带来的：从上面或下面看帽檐时，边缘里侧有一条和描边差不多粗的线，帽檐像是卷了边。参考的帽檐只有外面一条轮廓。
- **帽檐的影子比参考的浅。** 影子的深浅跟着帽檐伸出多远走。现有帽子的帽檐都只比头宽一点（牛仔帽宽 8%，大檐帽的帽舌最宽），参考的宽檐帽要宽出六成以上。做一顶真正宽檐的帽子（草帽、宽檐牛仔帽），影子会自己跟上，不用改着色器。
- **待机时身体有呼吸起伏**（上下 1.2%，3.6 秒一次，`breathe`）。参考没有这种循环。要不要去掉还没定。
- 测试片里人会走出画面边缘、互相挡住，这是测试镜头的机位，不是角色的问题。
