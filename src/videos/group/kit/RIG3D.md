# 立体角色 rig3d

手绘感的立体角色：`src/videos/group/kit/rig3d.ts`。按参考视频的画法做的（一团不规则的头上贴一张 2D 的脸，衣服包在身体上，头发画在头上，细的四肢，毛笔粗细的描边），和纸片角色 `kit/cast.ts` 用同一套 Look、同一个 CastLight，表情名字和 `toon.ts` 的 `Expr` 一样。

2026-11-10 做，依据是两张参考截图和 11 条参考视频里随机抽的 198 帧。对比图、动态对比和抽帧研究不在仓库里（里面有参考视频的画面），在项目共享文件夹 `character-3d-look/ours/`。

## 这是什么

参考博主的角色做法在我们自己管线里的实现：`src/videos/group/kit/rig3d.ts`，一个文件。
它和现在的纸片角色 `kit/cast.ts` 用同一套 Look（YOU、RESEARCHER、classmate(seed)）、同一个 CastLight（例如 LAB_CAST_LIGHT），接口也基本一样（`set` / `handWorld` / `update`），表情的名字和 `toon.ts` 的 `Expr` 一样，所以旧镜头里的表情可以直接换过来。

全部是代码画的：头、五官、头发、帽子、描边、明暗都在这个文件里，每个角色的不规则按固定的种子算。同样的输入每次出来的画面一样，渲染时没有任何模型参与。以后的片子只要“用”这个文件，画风就不会变；要改画风才需要动它。

## 参考的五官是怎么画的（在 198 帧随机抽帧里放大 60 多个头量的）

单位 u 是头的填色宽度的 1%。

1. 所有线条是同一支圆头笔，粗约 3.0 到 3.3u。旧版的眉毛和眼睛是粗的楔形，这是最大的差别。
2. 两眼在中线两侧各约 14u。默认的眼睛是一条约 20u 的眼皮线，下面挂半个圆瞳孔。其他眼睛：竖的圆点（约 10 × 13u）、圆圈眼（约 24u，里面一个小瞳孔）、笑眼弧线（约 18 × 8u）、一条平线、“＞ ＜”。
3. 眉毛是简单的弧线，长约 18u，离眼皮线约 12u，常常一高一低。
4. 嘴在眼线下面约 19u，很小：默认是一个约 10 × 4u 的小扁嘴；微笑是约 17u 的弧线；大笑是约 40 × 13u 的张嘴，里面一排分开的牙；龇牙是一个约 26 × 17u 的圆角框，画成牙格；还有小圆嘴和波浪嘴。
5. 情绪符号：汗滴、脸红、怒气符号、速度线。
6. 戴眼镜的人，镜片本身就是眼眶，里面只画瞳孔。
7. 头发是平涂加描边：发际线有一条墨线，有分缝，有几条浅色发丝，刘海压得很低。

## 参考的手绘感从哪来（在长椅那帧上量的，第三版）

1. 头不是正圆，是略扁、不对称的一团，宽大约是高的 1.1 到 1.2 倍。
2. 描边有粗细：受光一侧约为头宽的 2%，背光一侧约 5%，下巴下面约 8%。身体的线和头的线一样重。
3. 颜色平涂，明暗是画上去的：
   - 头：白底，沿背光一侧和下缘有一条淡紫色带，宽约头宽的 7%，边缘是软的。
   - 衣服：受光一侧约 15% 宽是一条浅色边，中间一半完全平涂，背光一侧约 30% 渐渐变暗（偏冷）。
   - 四肢：接近墨色的平涂，受光一侧靠里有一条平的浅色带，宽约肢体的四分之一。
4. 头完整地画在身体前面，下巴的线压住衣领。
5. 比例：头约占身高三分之一；头圈以下看得见的身体宽约 0.57 个头宽、长约 0.8 个头宽；腿约 1.18 个头宽；手臂约 0.8 个头宽。

只凭截图分不出参考是 2D 画贴在卡片上，还是处理过的 3D 模型，两种都说得通。

## 我们怎么做到的

`RigCast` 有一个 `hand` 参数：0 是干净的几何体，1 是参考那种手绘程度（默认）。

- 五官：一张平的 2D 画，按上面那套零件画，23 个表情。它按位置贴在头上（不跟着头的起伏弯曲），按远近缩放（任何镜头距离下在头上一样大），画在头发上面（挑起的眉毛可以压过刘海），只有帽子能盖住它。每个角色的眼睛大小和左右略有不同，按种子固定。
- 眨眼只有两格（半闭、全闭），没有中间帧。视线 `gaze` 以 0.5 为一档，瞳孔在眼皮线下面滑动。
- 头发直接画在头上（同一个面，发际线不会有两个面打架的亮点）：平涂、发际线墨线、分缝、几条浅色发丝，刘海压低。线是着色器里算的，细到不足一个像素之前先淡出。
- 帽子：鸭舌帽有画出来的缝线和一圈压线，毛线帽有罗纹。帽子下面的头发只从鬓角往后露出来。帽檐是从帽圈下面长出来的一块楔形，不碰头，没有外壳描边，墨线直接画在帽檐边上。帽子先画，头让开帽子占的像素。
- 形状不规则：头用 Look 里已有的头形再加一点起伏；身体两侧略有起伏；四肢微弯、粗细略变；脸和衣服的图案整体轻微扭一下。
- 描边像毛笔：朝光一侧细，背光一侧和下面粗，沿线还有缓慢的粗细变化。
- 明暗是画的，不是算的：没有真实光照的渐变，只有量出来的那几条带子。
- 头压在自己的身体和四肢上面，但对别的角色、道具、布景保持真实的前后关系（用模板缓冲做的，见“接入正片”）。
- 所有不规则都按角色的种子固定，跟着部件走，不逐帧变化。没有“线条抖动”这种效果，是为了守住不闪烁的规矩。

## 运动规则

1. 脸的方向离镜头最多 12°（`FACE_MAX`），只朝人物面对的一侧挪一点。不出侧脸。
2. 身体朝镜头转，离镜头最多 45°（`BODY_MAX`）。衣服是包在身体上的一张图，镜头一动自己就有透视。
3. 头发和帽子跟身体转，脸几乎不动，两者错开是立体感的主要来源。
4. 两个坐标系：行进系（脚、步幅、拉绳的后仰，钉在世界里，镜头或身体转动时脚不滑）和展示系（朝镜头转的躯干、手臂、头）。
5. 背面：人物朝向离镜头超过约 115° 后连续过渡到真正的背面，脸到头的边缘时淡出。也可以用 `state.turn`（0 到 1）手动控制，建议用 8 到 12 帧做转身。
6. 手臂有净空求解：肘部绕肩到手的轴转动，直到整条手臂连同描边都不碰身体。个别体型在肩膀下面还是贴到身体时，整条手臂往外让，一次 1 毫米，最多 8 毫米（只对没有钉在世界里的手）。每帧可以读 `rig.qa.clear`（小于 0 就是穿模）和 `rig.qa.reach`（大于 0 就是够不着）。
7. 描边最细不小于 1.6 像素，远景里细线不会闪。

## 用法

```ts
const rc = new RigCast(scene, { light: LAB_CAST_LIGHT });          // 可加 hand: 0..1
const a = rc.add(YOU);                                   // 或 rc.add(look, { hat: { kind: "cap", col: "#3f6b8f" } })
// 每帧：
a.set({ at, facing, pose: { kind: "haul", t, amount: 0.85 }, hands: [worldA, worldB], twist: 0.75, expr: "huff", blink, gaze });
rc.update(camera, renderHeightPx);
rope.update({ a: a.handWorld(1), ... });                 // 绳子等在 update 之后取手的位置
```

- 表情（`RIG_EXPRS`）：neutral、smile、happy、grin、laugh、smile_closed、relief、relief_open、smug、deadpan、focus、stern、huff、sad、sigh、nervous、shock、dazed、pained、wince、whistle、lick、sleep。
- `state.blink`：0 睁开、0.5 半闭、1 闭上。`state.gaze`：-1（画面左）到 1（画面右），0.5 一档。
- `rigFaceCanvas(look, expr, { lid, gaze, brim })`：单独拿一张脸的画（出表情表、检查用）。
- 已有姿势：`idle`、`walk`、`wave`、`point`、`haul`、`hold`（拿板子）、`cheer`。
- `state.twist`：躯干相对脚的朝向自己再转多少（弧度，正数朝人物的左边）。手臂短（0.84 个头宽），身体不转的话够不到身侧的绳子，所以拉绳的人要朝绳子转。
- `state.headFront`：默认 1，头压在自己的身体上面；0 是按真实前后关系画。
- 人物自己的手不会画在自己的头前面，所以挥手、欢呼的手摆在头的旁边或下面。
- 镜头规则：不要让人物朝向停在离镜头 115° 到 170° 之间（那是转身过渡区）；要背面就用 `turn = 1`；用后仰和前倾表现用力，不拉伸头。

## 怎么出图（在仓库根目录）

需要：`npm ci` 装好依赖；带 Chromium 的 Playwright（Claude 的云端环境里自带）；`ffmpeg`；Python 的 numpy 和 Pillow。

1. 单帧：`bash scripts/rig3d/shot.sh src/videos/group/preview/rig3d_trio_rig.ts out.png`，大约 10 秒（84 人那张约 30 秒）。
2. 多帧：`bash scripts/rig3d/frames.sh src/videos/group/preview/rig3d_orbit720_rig.ts outdir 120 720 1280`。只出其中几帧：`bash scripts/rig3d/pick.sh <入口> outdir 540 960 4 6 40`。
3. 23 个表情：`bash scripts/rig3d/frames.sh src/videos/group/preview/rig3d_exprs_rig.ts outdir 23 480 480`。
4. 类型检查：`npx tsc -p scripts/rig3d/tsconfig.rig.json`，`n8ao` 的 TS7016 报错可以忽略。
5. 闪烁扫描：把帧合成 mp4 后 `python3 scripts/rig3d/scan.py clip.mp4 outdir 帧数`。
6. 逐像素闪点：`python3 scripts/rig3d/sparkle.py <帧目录> [对照帧目录]`。单像素孤点：`python3 scripts/rig3d/specks.py <帧目录>`。
7. 放大检查：`preview/rig3d_capbig_rig.ts` 是戴帽转身的 2160×3840 版本，配合 `pick.sh` 出单帧。

预览每帧会在控制台打印 `QA: frame N reach X clear Y`（第 0 帧，以及任何 reach 大于 0.012 或 clear 小于 -0.0005 的帧）。

## 接入正片还要做的事

- **模板缓冲**：正片的 `Film.tsx` 里 `<EffectComposer multisampling={4}>` 要加上 `stencilBuffer`。没有它，头压不住自己的身体，下巴的线会被衣领切掉，帽子也压不住头。角色分三步画（`renderOrder` 0、1、2，帽子和头在 0 之前），每帧开头自己清模板。正片还有描边、景深、泛光、调色几道后期，预览里没有，接入后要在正片的一帧上再查一次。
- 《为什么总有人划水》用到而新角色还没有的姿势：`desk`（坐在课桌前）、`write`、`reach`。宿舍那段还要 `curl`、`phone`、`sitUp`。纸片角色另有 `jog`、`lookDown`、`dragged`、`throw`、`cardUp`、`dust`。
- 手在脸前面的姿势（打电话、捂脸）现在画不出来，手会被自己的头盖住，要给手臂加一个开关。
- 角色只投影、不受影（见上表第一项）。
- 和布景（桌椅、床）的防穿模还没有，只有手臂对自己身体和头的检查。
- 描边经过后期（环境光遮蔽）之后比参考更黑：屏幕上约 (8, 4, 19)，参考约 (32, 26, 46)。把描边颜色提亮可以解决，但提亮后环境光遮蔽的噪点可能在线上闪，所以没动。

- 84 人一起出一帧：`qa.clear` 最小是 0，没有穿模；角色更新每帧约 160 毫秒。修之前有一个人的手臂描边贴进身体 0.3 毫米，所以加了“整条手臂往外让”的那一步。

这一轮查出来并修掉的：

1. 镜片里的圆圈眼成了双圈：改成镜片就是眼眶。
2. 视线移动太小看不出来：加大到 3.6u。
3. 帽圈和帽檐之间有一条白缝，额头上有一条一像素的细线，帽檐下有碎点：都来自帽檐的外壳描边。薄片的外壳描边在侧对镜头时会变成发丝线或一排点，所以帽檐不再用外壳描边，改成楔形，墨线画在上面。
4. 帽子下面的刘海从帽圈边上露出一条：帽子下面的头发改成只从鬓角往后露。
5. 帽子上偶尔有一个像素的浅色点：头的轮廓在帽子下面，渲染器给侧对镜头的三角形的某一个采样点算错了深度，头的颜色就透到帽子上。改成帽子先画、头让开帽子的像素。放大到 2160×3840 的那一帧上原来有 3 个点，现在是 0。

## 已知的小问题

四肢上还有零星的单像素点（`specks.py`），帽子和衣服上偶尔也有一个深色的点：原地转身 61 帧里 9 个，戴帽转身 61 帧里 15 个（修帽子之前是 19 个）。原地转身里的位置和上一版完全一样，不是这一轮带来的。原因和上面第 5 条相同：预览和渲染农场用的都是软件渲染器（SwiftShader），4 倍抗锯齿下，侧对镜头的细三角形偶尔有一个采样点深度不对，身体的颜色从手臂的描边里透出一个点。每个点只有一个像素大，大多只出现一帧（有一个停了五帧）。我的判断是在手机上看不出来，但没有在正片的成片上验证过。

在戴帽子那一帧上试过：关掉抗锯齿后这些点消失。所以接入正片时如果在意，可以试“不开多重采样，改成 2 倍尺寸渲染再缩小”。四肢上的点没有单独做这个试验。
