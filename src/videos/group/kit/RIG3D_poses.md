# 立体角色：坐下、写字、看手机、打电话

`kit/rig3d.ts` 的新姿势，给教室和宿舍的片子用。角色本身的画法见 `kit/RIG3D.md`，这里只讲新加的部分。

2026-11-10 做，同一天合到了带角色道具、说话和走路的新版 `rig3d.ts` 上（合并后重新查过，见最后一节）。检查用的图不在仓库里（只提交了代码和回归用的哈希）。

## 加了什么

| 文件 | 内容 |
|---|---|
| `kit/rig3d.ts` | `state.seat`（坐在哪）、`state.armFront`（手臂画在自己的头前面）、姿势 `sit` / `desk` / `write` / `phone`、`qa.seat` 和 `qa.head` |
| `kit/rigacc/phone.ts`、`kit/rigacc/pen.ts` | 手里的手机和笔（两个配件，道具清单 `catalog.ts` 里叫 `phone`、`pen`） |
| `preview/rig3d_pose_qa.ts` | 不出图的防穿模检查，`scripts/rig3d/acc_check.py` 的第 6 步跑它 |
| `preview/rig3d_poses_common.ts`、`preview/rig3d_pose_*.ts` | 预览：一把椅子、一张课桌，各个姿势的入口 |
| `scripts/rig3d/golden/cases_poses.json`、`hashes_poses.json` | 新姿势的回归图（360×640） |

站着的角色没有任何变化：原来的回归图逐像素相同（合并前是 43 张，合并后是 121 张）。

## 用法

```ts
import { phone, pen } from "../kit/rigacc/index";     // 或者按名字取：accessories("phone")、accessories("pen")

const a = rc.add(look, { acc: [pen()] });            // 写字的人手里有笔（默认右手）
const b = rc.add(look, { acc: [phone()] });          // 拿手机的人（默认左手）

// 坐在课桌前写字。seat.top 是椅面中心（世界坐标），deskEdge 是从椅面中心到桌子近边的距离
a.set({ at, facing, seat: { top: V(x, 0.456, z), deskEdge: 0.23, deskTop: 0.75 }, pose: { kind: "write", t } });

// 手机：amount 0 是低头看，1 是放到耳边。站着坐着都可以
b.set({ at, facing, pose: { kind: "phone", t, amount } });
rc.update(camera, renderHeightPx);
```

有 `seat` 时人就坐在那里，`at` 不起作用（可以照常传）。手的编号和原来一样：0 是人物的右手，1 是左手。

## 字段

### `state.seat`

和纸片角色 `kit/cast.ts` 的 `seat` 是同一组字段，旧镜头可以直接搬过来。单位是米，世界坐标。

| 字段 | 意思 | 默认 |
|---|---|---|
| `top` | 椅面上表面的中心 | 必填 |
| `back` | 屁股坐在这个中心后面多远（负数是往前坐） | 0.03 |
| `front` | 从中心到椅面前沿的距离，膝盖在前沿外面一点弯下去 | 0.2 |
| `deskEdge` | 从中心到桌子近边的距离（顺着人物的朝向）。不写就是没有桌子 | 无 |
| `deskTop` | 桌面的高度（世界 y） | 0.75 |
| `floor` | 地面的高度（世界 y）。腿够得着地，脚才踩地 | 0 |
| `backrest` | （cast.ts 没有）从中心往后到椅背前表面的距离。写了它，人不会坐进椅背，手臂也不会伸到椅背里 | 无 |
| `backrestTop` | 椅背上沿的高度（世界 y）。高过它的地方没有东西挡 | 椅面上 0.42 |

椅面当成一条长凳来算：左右不限宽，椅面以下、前沿以后都是实心的。桌子当成从近边往前的一块 6 厘米厚的板，腿可以伸到下面。

不写 `seat` 而姿势是 `sit` / `desk` / `write` 时，人坐在 `at` 上方 0.472 米高的一个看不见的座位上（纸片角色也是这样）。这时没有桌子，手放在腿上。

### 姿势（`pose.kind`）

| 姿势 | 做什么 |
|---|---|
| `sit`（`desk` 是同一个姿势的另一个名字） | 坐着。没有桌子时两只手放在自己的大腿上；有桌子时两条前臂平放在桌面上，身体略往前倾 |
| `write` | 坐在桌前写字。`pose.arm`（默认 0，右手）拿笔在桌面上一小段一小段地写，另一条前臂放在桌上，头略低。由 `pose.t`（秒）驱动，同一个 `t` 永远是同一个画面。没有桌子时手放在腿上 |
| `phone` | `pose.arm`（默认 1，左手）拿手机。`amount` 0：手机在胸前，屏幕朝脸，头低下去看；`amount` 1：手机贴在耳边，头抬平；中间是平滑的过渡。站着坐着都可以，另一只手垂着（坐着时放在腿上或桌上） |

原来的上半身姿势坐着也都能用：`idle`（坐着时和 `sit` 一样）、`wave`、`cheer`、`point`、`hold`。本来会垂下来的那只手，坐着时改成放在腿上或桌上。`walk` 和 `haul` 是站着的姿势，坐着时按 `sit` 处理。

### `state.armFront`

`[右手, 左手]`，每一项可以是 `true`、`false` 或不写。

- `true`：这条手臂、手、手里的东西按真实的前后关系画在自己的头上，所以可以出现在脸前面。这时它们被严格挡在头的真实形状外面（连头发、帽子的形状一起算），不会穿进头里。
- `false`：和以前一样，被自己的头盖住。
- 不写：由姿势决定。`phone` 会自动把拿手机的那条手臂设成 `true`，其他姿势都是 `false`。

只影响写了 `true` 的那条手臂，另一条手臂和以前完全一样。两条都不写时，画面和以前逐像素相同。

### 配件

- `phone({ col?, hand?, screen? })`：手机，默认玫红色、左手（`hand: 1`）。
- `pen({ col?, hand? })`：笔，默认蓝色、右手（`hand: 0`）。

`hand` 要和姿势的 `pose.arm` 是同一只手。不想让手机一直出现，用原来就有的 `state.hide = ["phone"]` 把它藏起来（比如还在口袋里的时候）。藏起来只是不画，那只手休息时仍然按手里有东西来摆（略高一点）。这两个配件没有加进 `kit/rigacc/index.ts`（那个文件由别人汇总），要从各自的文件导入。

手机和笔是“姿势会拿的东西”（`PartKit.held` 的新选项 `posed: true`）：写字时笔斜着立在纸上，看手机时屏幕朝脸，打电话时屏幕贴着头的侧面，手放在腿上或桌上时东西平压在手下面。别的姿势里它们按原来的固定方式跟着手。公文包这类旧配件没有任何变化。要做新的手持物，照着 `phone.ts` 抄：长的方向沿 +y，正面朝 +z，原点放在手握的位置。

### `rig.qa`（`update` 之后读）

| 数字 | 意思 |
|---|---|
| `clear` | 手臂离自己的身体、头、配件占位球的最小距离；坐着时也算椅面、桌子、椅背。小于 0 就是穿模 |
| `reach` | 手离它该在的位置有多远。0 是都够得着 |
| `seat` | 坐着时：腿、脚、手臂、手、手里的东西、身体，离椅面、桌子、椅背、地面的最小距离，以及手臂离自己的腿的最小距离。没坐着是 1 |
| `head` | 画在头前面的那条手臂（连手和手里的东西）离头的真实形状的最小距离。没有这样的手臂是 1 |

预览每帧打印一行 `QA: frame N reach X clear Y | ...`，这里的 clear 是 `clear`、`seat`、`head` 三个里最小的。

## 坐姿是怎么摆的

1. 屁股压在椅面上（身体底部比椅面高 2.8 厘米，正好是描边的厚度，线不会和椅面打架）。不靠“往下蹲”来坐。
2. 大腿在行进系里朝前平放在椅面上，膝盖刚过椅面前沿，小腿垂下去。腿和脚由座位决定，不跟着躯干转，也不跟着呼吸动，所以坐着的腿是完全静止的。
3. 腿够得着地面、而且不用穿过椅面时，脚才踩在地上；够不着就悬空垂着。这些角色腿短（大腿加小腿约 0.58 米），坐在 0.456 米高的椅子上脚是悬空的，椅面降到 0.30 米左右才踩得到地。座位再矮，膝盖会抬起来。脚悬空时脚下的接触阴影不画。
4. 躯干朝镜头转的角度有限：椅子上最多 20°，桌前最多 14°（转多了前臂在桌面上会扭）。剩下的由头来转（头在身体上最多再转 46°），所以脸、头发、帽子还是像站着时一样跟着镜头。个别体型两只手够不到休息的位置时，这个角度会自动再小一点。
5. 手放在腿上：放在自己那条大腿的外侧半边，尽量靠近膝盖。手臂很短（比肩膀到椅面的距离还短），所以手其实停在肚子前面一点。身体宽、手臂短的体型手够不到大腿，就悬在大腿上方（最多约 5 厘米）。位置是按“不晃的身体”定的，每个座位只定一次，所以身体呼吸、轻轻左右晃的时候手不动，镜头绕着人转的时候手也不动。
6. 手放在桌上：两条前臂平压在桌面上，手在胸前略分开。桌子离得远时，手往肩膀方向收，但不会收到桌子外面。
7. 坐着挥手、欢呼：这两个姿势的手本来摆在“正对镜头的平面”里。坐着时躯干转不过去，所以这个平面最多只跟着镜头转到离躯干 45° 的地方。

## 手机在脸前面是怎么画的

头本来是整个压在自己的身体和四肢上面的（见 RIG3D.md“运动规则”）。`armFront` 给每条手臂一套自己的材质：打开时，这条手臂不再让着头，按真实深度和头比。因为按真实深度画，手臂必须真的在头外面，所以这条手臂的净空是按头的真实形状（包括头发、帽子）算的，手机的每个角也都算进去。

头的描边是一层往外推的壳的背面，比头的轮廓靠后最多十来厘米。只按真实深度比的话，一部躲在头后面的手机会盖住这圈线，头在那一段就没有描边了。所以只要有手臂设成了 `armFront`，就在头的轮廓所在的那个平面上多画一张只写深度、不上色的圆片（只落在头自己的像素上，画在头之后、四肢之前）：在头后面的东西，也在头的描边后面；在头前面的东西照常盖住描边。这张圆片只在 `armFront` 打开时才有，关着的时候画面和以前逐像素相同。打开时下巴下面那一小圈接触阴影会有 1 到 3 级（满 255 级）的变化，肉眼看不出来。

打电话时手机贴在脸所朝的那一侧的头上（脸是画出来的正面，手机要贴在看得见的那一侧才像），但离身体自己的侧面不超过 50°，这样手臂才够得着。

## 摆镜头的建议

- 桌子近边离屁股 0.20 到 0.30 米时最好看：两只手和笔都能自然地放上桌面。预览用的是椅面中心到桌边 0.23 米（加上默认的 `back` 0.03，就是屁股到桌边 0.26 米）。
- 教室布景 `sets/classroom.ts` 的 `seats[i].pos` 已经是屁股的位置（y 0.472），所以用 `seat: { top: pos, back: 0, deskEdge: 桌边距离, deskTop: 0.75 }`。那里屁股到桌边有 0.30 到 0.41 米，偏远。到 0.33 米为止和近的桌子一样；再远，手要伸直去够，身体多往前倾（最多再多 8°），躯干也渐渐不能朝镜头转（0.36 米时只剩 5° 到 12°，0.41 米时完全不转）。没有穿模，但姿势是绷着的。建议把 `back` 设成负数让人往前坐（比如 `back: -0.08`），让屁股离桌边在 0.25 到 0.33 米之间。注意教室的 `facing` 约定和角色不一样（教室的 0 是朝黑板），角色的 `facing` 要用 `Math.atan2(dir.x, dir.z)` 从座位的 `dir` 算。
- 想让脚踩地，椅面要在 0.30 米左右或更矮；正常高度的椅子上脚悬空是这些角色的正常样子（参考视频里坐着的人也是腿垂着的）。
- 拿手机默认用左手（`arm: 1`）。镜头在人物的哪一侧，就用哪一侧的手，手机和手臂不会挡住脸。从举手机那一侧的正侧面看，手和手机会盖住一部分脸，这是真实的遮挡，不是穿模。
- 举起、放下手机：把 `amount` 用 8 到 12 帧从 0 动到 1（内部已经做了缓入缓出，线性地改 `amount` 就行）。
- “低头看手机”时头会低 17°，但脸还是按老规则朝着镜头（离镜头最多 12°），不会真的转向手机。需要更明显的“在看”，加 `state.lookDown` 或者换表情（`focus`、`deadpan`）。写字时头低 13°。
- 坐着的人也不要让朝向停在离镜头 115° 到 170° 之间（转身过渡区，脸正在淡出）。要拍背面就用 `turn = 1`。从正后方拍坐着的人是可以的。
- 一排人坐着时，和站着一样，给每个人设同一个 `turn`，免得有人正面有人背面。
- 椅背：把 `backrest` 写上，手臂和手机就不会伸进椅背。不写也能用，只是不检查椅背。
- 戴帽子打电话没有问题，帽檐、帽圈的形状都算在头的真实形状里。

## 和说话、头部动作、角色道具一起用

- 坐着的人照常说话：`rigSpeak` 给的 `mouth` 和 `head` 直接传进 `set`，和站着时一样。头部的重音动作（放大、压扁、歪头、上下移）时，贴在耳边的手机和那只手跟着头走。
- 坐着时躯干转不了多少，所以头是真的在身体上转过去的；歪头叠加在这个转动上。
- 戴帽子、戴耳机都可以打电话：手机贴在帽子或耳罩的外面，不会穿进去。
- 手放在头旁边时（挥手、打电话），头做重音动作的那 3 帧里手会给头让位：挥手的手让 1 到 2 厘米；戴着耳机打电话、手臂又短的体型，手会停在手臂伸直能到的最远处。这是有意的，手不会穿进头里。
- 给坐着的人 `walk`、`haul`、`idle`，都按“坐着不动”处理。
- 提着公文包这类“挂在手上”的东西（`hang`）的人坐下时，那只手照样放到腿上或桌上，包会穿过腿和椅子。坐下的镜头里用 `state.hide = ["briefcase"]` 把包收起来，在布景里另放一个。咖啡杯这类不是为姿势做的手持物，坐着时按固定方式跟着手，它和桌面、腿之间不做防穿模，也没有专门查过：要用就先出图看。

## 限制和已知的问题

- 没有做 `reach`（伸手够东西）、`curl`、`sitUp`、躺着。这次只有坐、写、手机。
- 椅面按长凳算，没有扶手，也不检查椅子腿和桌子腿。人和别人、和别的道具之间不做防穿模检查，摆位置时自己留出距离。
- 坐着时躯干最多转 20°（桌前 14°），所以从侧面看坐着的人，身体是侧的，只有头转过来。这是为了手和腿都不穿过桌椅。
- 手臂短：手放在腿上时停在肚子前面，够不到膝盖；身体宽的体型手是悬在腿上方的。
- 桌前坐着（两条前臂放在桌上）、镜头绕到侧面时：大约一半的体型，肩膀往后摆的那条手臂要绕过肚子，肘会抬起来让开身体。这个动作是连续的，方向也不变，但比较快：躯干转角从约 10° 到 14° 的这一段里，肘抬高几厘米。镜头每秒转 75° 时，肘每帧最多动 2.2 厘米（其中约 1 厘米是躯干自己在转）；正常的镜头速度下每帧不到半厘米。手放在腿上、写字都没有这个现象。试过把桌上的两只手分开放来避免它：绕拍时肘确实不再抬，但身体轻晃时肘会一阵一阵地快动（每帧最多 8 毫米），所以没有采用。
- 写字的笔画是固定的一小段循环（每秒 2.2 个小圈，每 2.4 秒从左到右写一行再回到行首），不会真的写出字。纸上的字要另外画。
- 回到行首的那一下手每帧移动约 1.2 厘米，是这个姿势里最快的动作。
- 举手机的 12 帧里手每帧最多移动约 5 厘米，逐像素闪点（`sparkle.py`）在这几帧里高（约 1600 个像素），因为手机本身在快速移动；停住时是 0 到 7 个。
- 软件渲染器的单像素孤点（RIG3D.md“已知的小问题”）在新姿势里同样存在，数量不比站着的同一个镜头多。
- 手机、笔只在 `write`、`phone` 和休息的手里会被摆正。拿着手机做 `wave` 之类别的姿势时，它按固定方式跟着手，不做防穿模。

## 怎么出图和检查（在仓库根目录）

```bash
# 14 个机位的一组（7 个方向 × 平视和俯视），540×960
node scripts/rig3d/render.mjs src/videos/group/preview/rig3d_pose_sit.ts outdir --frames 14
# 写字 48 帧、举手机 48 帧、绕坐着的人一圈 72 帧
node scripts/rig3d/render.mjs src/videos/group/preview/rig3d_pose_write.ts outdir --frames 48
node scripts/rig3d/render.mjs src/videos/group/preview/rig3d_pose_phone.ts outdir --frames 48
node scripts/rig3d/render.mjs src/videos/group/preview/rig3d_pose_orbit.ts outdir --frames 72
# 换人、换姿势、换机位：用 --opts 覆盖入口里的选项（字段见 rig3d_poses_common.ts 的 PoseLabOpts）
node scripts/rig3d/render.mjs src/videos/group/preview/rig3d_pose_sit.ts outdir --frames 14 \
  --opts '{"who":[{"look":"class7","hat":{"kind":"cap","col":"#3f6b8f"},"pose":"phone","amount":1,"acc":["phone"],"seat":"desk"}]}'
# 回归：站着的图和新姿势的图都要“相同”
python3 scripts/rig3d/regress.py --jobs 2
# 全套检查（六步，最后一行是 ALL GOOD 才算过）。第 6 步专查这些姿势：13 种体型、4 种座位、16 个机位，
# 头不动和做重音动作各查一遍，手里有手机或笔，头上有耳机或帽子，任何东西都不能穿过身体、头、椅子、桌子
python3 scripts/rig3d/acc_check.py
```

入口：`rig3d_pose_sit`（椅子上坐着）、`rig3d_pose_desk`（桌前坐着）、`rig3d_pose_write`（写字）、`rig3d_pose_phone`（站着看手机、打电话）、`rig3d_pose_phone_seat`（戴帽子的人坐在桌前用右手打电话）、`rig3d_pose_orbit`（镜头绕坐着的人转一圈）、`rig3d_pose_row`（四个人一排，各一个姿势）。
