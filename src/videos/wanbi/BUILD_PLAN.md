# 《完璧归赵》 build plan (WanbiFilm)

What to build, in which files, in which order, by whom. Read `BIBLE.md` (the world) and `STORYBOARD.md` (the shots)
first. The model is Hongmen: same file shape, same World contract, same tools. Where Hongmen kept its own copy of a
kit file (acc/, fx/, props/kit.ts, sets/okit.ts), Wanbi IMPORTS the shared kit (`src/kit/`) instead.

Ground rules for every package:
- Never edit `src/kit`, `src/videos/group/kit`, `vasa/`, `bt/`, `arthur/`, `hongmen/`, `scripts/rig3d`,
  `scripts/arthur`, `scripts/hongmen`, `scripts/kit`. Import from them; copy a file into `wanbi/` or `scripts/wanbi/`
  when it needs changes. A needed kit change goes into section 6, never into the kit.
- No commits, pushes or PRs. No media in the repo. Pictures, logs, scratch files only under `/home/user/wanbi_work/<wp>/`.
- Renders only through the queue, at 540 x 960, one at a time, within the package's still budget (section 3). 3D only:
  `bash scripts/kit/queue/still.sh <entry.ts> /home/user/wanbi_work/<wp>/ --pick F1,F2 --size 540x960`. Anything with
  captions, tags, stamps or HUD: `bash scripts/kit/queue/remotion_still.sh WanbiFilm <frame>
  /home/user/wanbi_work/<wp>/f<frame>.png` (slower: budget queue time for it).
- After every change `bash scripts/kit/tsc.sh --film wanbi` is clean; from WP1b on also `bash scripts/kit/qa/clearance/
  run.sh --film wanbi [--seg A]` (no render before the checker is clean).
- Every frame number comes from `beats.ts` / `line()` / `cap()` / `capWord()` / `quote()`; every mark and camera from
  `layout.ts`; every on-screen string is `L(zh, en)`.

## 2. The World contract (what segments may call)

```ts
pose(w: World, f: number): Pose            // pure: same f -> same picture; may be the first frame of a chunk
  w.setPlace("hall" | "zhao" | "road")     // shows one island, sets its look and light
  w.set.setCeremony(0..1); w.set.setMapStand(on)          // setView is called by endFrame, never by a segment
  w.setCamera(CAMS.hook)                   // or a mixed CamPose (camMix) for moves and whips
  const r = w.actor(LIN); r.set({ at, facing, pose, expr, gaze, turn, hands, seat, visible, ...speak(q, f, id) })
  //  speak() returns { mouth, head, blink }; kneel = Hongmen kneel(k, p, deg), which lowers `at` by KNEEL_DROP 0.38
  const hand = HALL.jade0;                 // pin the hand to a computed point and put the prop at the same point
  w.prop("jade").put(hand, { scale: 1.5, grip: "rim" })    // beginFrame hides every prop
  //  r.handWorld(i) exists, but only after w.update(); before it, it returns the previous frame's solve
  w.project(v) -> {x, y, z, front, on}     // HUD that follows the world (cities on the map, ring, stage circle)
  return { camera, clock?, hud?: boolean, overlays?: ReactNode }   // Film calls w.endFrame(P)
```

An actor swap (`LIN` -> `LIN_RAGE`) = two actors, one visible (`swapTo`; Hongmen's `swaps()` is the blink helper). A
person a shot does not set is hidden by `beginFrame`; each shot sets exactly its STORYBOARD "placed" list.
