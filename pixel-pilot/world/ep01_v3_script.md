# 第一集（第三版）《三十秒的黑暗》

纯字幕版，不配音，用Jay的BGM从头开始。时长目标2分20秒到2分40秒。

## 1. 为什么换

《消失的13号房》的问题：画面一出来，观众就知道"房间还在墙后面"，推理只剩数窗户，没有意外。

这一版改成"灯灭前后找不同"：
- 灯灭之前，福尔摩斯让你"看清楚每一个人"。这本身就是一个游戏，观众会主动去记。
- 灯亮之后，**每个人都有变化**，大部分是好笑的、无关的（鸽子落在魔术师头上、夫人哭花了脸、画家打翻水罐），真正有用的只有两三处，而且很小。
- 找到宝石的人会以为自己破案了（宝石在画家的画里），其实那是第二个坑。真凶要靠一条"说漏嘴"的台词和一个冷知识才能抓到。
- 解答有三次反转：不是魔术师 → 宝石在画里，但不是画家 → 一个说自己怕光的人，灯亮后却把墨镜翻了上去。

## 3. 场景

- 客厅（灯灭前）：窗边丝绒垫上放着一颗蓝宝石（不是项链，是一颗裸石）；旁边画架上是一幅还没画完的静物，画的就是丝绒垫上的蓝星；右边钢琴；门边墙上是投币煤气表；墙上挂钟。
- 客厅（黑暗）：只剩窗外月光，钢琴那边飘出音符，画架那边一声"哗啦"。
- 客厅（灯亮后）：丝绒架空了。
- 画的特写（灯灭前/灯亮后）：灯亮后，画里那颗蓝宝石多了一个白色高光，轮廓更深，像是凸出来的。**不点出。**
- 片尾墨线版：上校的眼镜铰链上三道铜绿刻痕///；一张交货条"十点四十五"，封着纯红火漆。最后一秒：格雷夫斯在速写本上画那只鸽子。

## 5. 解法和公平检查

- **宝石在哪：** 画里。灯灭前画上的蓝宝石是平的一点蓝，灯亮后多了高光和深色轮廓。莉莉自己说过"颜料还没干"。
- **是谁：** 上校。三条互相独立的线索：
  1. 他说"漆黑一片"，又说"看见莉莉动了一下"，自相矛盾；
  2. 他说自己怕光、戴深色镜片，灯亮后镜片却翻上去了（深色镜片让眼睛提前适应黑暗）；
  3. 白手套指尖的蓝颜料。
- **他怎么知道灯什么时候灭：** 管家当着所有人说过"九点四十五投了一先令，够烧一个钟头"，挂钟走到十点四十五灯就灭了。
- **排除：** 魔术师的琴声一直没停（黑暗里音符一直在飘）；莉莉打翻了水罐，说明她看不见，而且谁会把赃物藏进自己的画里；管家一直在门边摸黑投币、划火柴点灯。
- **灯怎么亮回来：** 煤气表在门边，管家摸黑投币，再划火柴把灯点上，前后三十秒。
- **两个坑：** 魔术师（"要不要我把它变没"）；莉莉（宝石在她的画里，上校又"看见"了她）。按设定，莉莉就是网卖的"现成的嫌疑人"。
- **和世界观的关系：** X:45（九点四十五投币、十点四十五灯灭）；网卖的"一件东西"是那副能翻起来的深色眼镜，铰链上有///；"现成的嫌疑人"是莉莉；纯红只在片尾墨线版的火漆上。

## 6. 盲测结果和修改

另一个没看过答案的AI只看暂停前的内容：宝石位置答对（把握90%），真凶答对（把握85%），理由完整。它估计普通观众：找到宝石约一半人（难度3/10），说出上校约四分之一（6/10），理由说全约一成（8/10）。大多数人会选莉莉或魔术师，正好是两个坑。

按它的意见改了：
| 问题 | 改法 |
|---|---|
| 煤气灯灭了不会自己亮，谁点的？ | 管家："煤气表就在门边。我摸黑又投了一先令，划火柴把灯点上。" |
| 项链藏不进画里 | 「蓝星」改成一颗裸石，莉莉画的就是它的静物 |
| 手套上几个像素的蓝点手机上看不见 | 蓝点放大到3×4个美术像素，灯亮后的人物卡上一定看得见 |
| 解答不够有画面感 | 解答时重放一遍黑暗，用上校的眼睛看：暗蓝色，但人人都看得清 |
| 结尾没回扣福尔摩斯的旧伤 | 最后一句改成"这一次，说出名字的是你。" |
