[0.0–4.6 s] 旅游标志上这匹马， / 三只脚悬空，只靠一只撑着。
[4.6–9.0 s] 7公斤多的铜马， / 全压在一只鸟的背上。
[9.0–13.5 s] (标题卡) 马踏飞燕， / 脚下踩的到底是什么鸟？
[13.5–17.9 s] 1969年秋，甘肃武威， / 村民挖防空洞，挖穿了一座古墓。
[17.9–22.4 s] 墓里，有一整支青铜仪仗队： / 马、车、人、牛，一共99件。
[22.4–26.9 s] 生产队的两匹耕马刚死， / 地下却挖出了39匹铜马。
[26.9–31.3 s] 有村民提议：把这些文物卖了， / 换钱，去买真马。
[31.3–35.8 s] 党寿山从县文化馆赶来劝： / 国家的文物，不能卖。
[35.8–38.0 s] 一只脚，怎么站得住？
[38.0–40.2 s] 东汉工匠，用了三招。
[40.2–44.7 s] 第一招：把重心压在鸟背上， / 偏出去，马就会翻倒。
[44.7–49.1 s] 第二招：让鸟当底座， / 张开的双翅，正好撑住平衡。
[49.1–53.6 s] 第三招藏在里面：X光一照， / 马腿里有铁骨头。
[53.6–58.0 s] 受力的腿根、脚踝和马蹄里， / 都加了铁芯：铁骨铜腿。
[58.0–62.5 s] 还有个细节：它在“顺拐”—— / 同一侧的两条腿，一起迈。
[62.5–67.0 s] 这叫“对侧步”， / 是汉代河西良马练出来的跑法。
[67.0–71.4 s] 甘肃至今还有这样的“走马”： / 骑着稳，颠得少。
[71.4–75.9 s] 1971年，郭沫若见到它， / 说它“天马行空，独来独往”。
[75.9–80.3 s] “马踏飞燕”这个名字，从此传开。 / 1973年，它去了巴黎。
[80.3–84.8 s] 巴黎之后是伦敦， / 它前后去过十几个国家。
[84.8–89.3 s] 1983年，它的侧面剪影， / 成了中国旅游标志。
[89.3–93.7 s] 2002年起，它被禁止出国展览。 / 想看它，只能来中国。
[93.7–98.2 s] 2022年，它变成一只绿色玩偶， / 一周卖出约2万个。
[98.2–102.6 s] 大家都叫它“马踏飞燕”， / 可它脚下，真的是燕子吗？
[102.6–107.1 s] 燕子的尾巴，像一把剪刀； / 这只鸟的尾巴，却是平的。
[107.1–111.5 s] 鸟头向后扭了180度， / 这是鹰隼类猛禽的特征。
[111.5–116.0 s] 鸟尾上，还有个小凹窝， / 可能是猎鹰系铃的地方。
[116.0–120.5 s] 考古学家初世宾认为： / 它是一只猎鹰，不是燕子。
[120.5–124.9 s] 也有学者说，它是乌鸦； / 还有人说，它是风神“龙雀”。
[124.9–129.4 s] 张衡的《东京赋》里， / “龙雀”和“天马”，写在同一句。
[129.4–133.8 s] 学者牛龙菲叫它“马超龙雀”： / 这匹马，比风神还快。
[133.8–138.3 s] 同一匹马，因为脚下这只鸟， / 有了一长串名字。
[138.3–142.8 s] 燕子？猎鹰？乌鸦？还是风神？ / 到底，谁说得对？
[142.8–145.0 s] 答案是——
[145.0–149.4 s] 至今，没有定论。 / 连甘肃省博物馆，也这么说。
[149.4–153.9 s] 所以，它的本名叫“铜奔马”—— / 名字里，没有鸟。
[153.9–158.4 s] 定名“铜奔马”的，正是初世宾， / 说它是猎鹰的那位。
[158.4–162.8 s] 说不准的，就先不写进名字。 / 但有一件事，可以确定：
[162.8–167.3 s] 不管它是什么鸟—— / 没有它，这匹马就站不住。
[167.3–171.7 s] 鸟刚回头，马已经冲过去： / 是它，让这匹马飞了起来。
[171.7–179.5 s] (片尾) 燕子、猎鹰、乌鸦、风神—— / 你觉得，它踩的是哪一只？
