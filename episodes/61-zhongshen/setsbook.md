# 古埃及神话故事 · 布景库（setsbook）

> 目的：让每一帧除了角色还有“东西”——塔门、柱廊、供桌、香烟、火盆、纸草、尼罗河、群众、小动物——而且全系列长得一样。**画法的唯一来源是代码**：`episodes/37-qiqing/remotion/src/qq61/sets61*.tsx`。本文是这套库的文字版：每件叫什么、怎么调用、画的是什么、依据哪件文物。

- 入口：`import {Pylon, Column61, Nile, OfferingPile, PriestProcession, SetDefs61, …} from '../qq61/sets61';`
- 设计册（目录）：`SETS61`（`src/qq61/setsbook61.tsx`，1440×1080，6 帧：帧 i = 第 i+1 页：建筑 / 自然 / 道具 / 动物 / 群众 / 氛围动效，t = 1.3 s 时的画面）。
- 示例场景：`SCENE61`（3 帧：夜·神庙前庭 / 黄昏·尼罗河 / 供奉大厅），看分层。
- 动效：`SETSANIM61`（30 fps，27 s = 6 页 + 3 个场景，各 3 s）。
- 渲染命令见 `tasks/ep61-sets/result.md`。不提交任何图片 / 视频 / 音频。

## 0. 通用约定（所有组件都一样）

1. **接口**：`<Piece x y s t … />`。
   - `x, y`：原点，单位 px。站在地上的东西 = 落地点中心；条带（河、天、沙丘、努恩）= 中心 x + 上沿 / 水线 y；手持物（手臂形香炉）= 握点。
   - `s`：px / 格。**格 = 角色骨架的单位**，阿尼连假发 20.1 格高。所以布景和演员用同一个 `s` 就是真实比例：柱子 18 格 ≈ 0.9 个人高，供桌 ≈ 4 格，啤酒罐 ≈ 2.5 格，猫坐着 ≈ 3.4 格。
   - `t`：秒。所有会动的东西都由 `t` 驱动；`t = 0` 也是一张合法的静帧。
2. **画法**：ep60 墓室壁画的方法——墨线外轮廓（约 2.6 px，与比例无关，`Sd`）在下，平涂在上。颜色取 `PAL`（青金、金、赤陶、绿松石、纸草米白、墨），石头 / 沙 / 水另加 `S61`。不画渐变阴影（天空、水、光晕除外）。
3. **方向**：动物与群众默认面向 +x；`flip = -1` 或 `face = -1` 镜像。
4. **错开节奏**：凡是成群的东西（纸草、旗、群众、鱼、雁、狮身像）都用 `seed` / 序号算各自的相位（`phaseOf`），**永远不会整齐划一**；同一场景放两组时换一个 `seed`。
5. **光**：火焰、光晕、香烟用 `url(#g60-*)` 渐变。用 `Stage60` 的场景已经有这些渐变；不用 `Stage60` 的画面要在 `<svg>` 里放一次 `<SetDefs61 />`（同名同色，另加天空 / 水的渐变 `s61-*`）。
6. **文件**：
   - `sets61_kit.tsx`：`Sd`、`Rod`、`Cornice`、`TorusV`、`Glyphs`、`SetDefs61`、`S61`、`phaseOf`、`wave`、`blip`。
   - `sets61_arch.tsx`：建筑。
   - `sets61_nature.tsx`：自然与氛围动效。
   - `sets61_props.tsx`：道具。
   - `sets61_animals.tsx`：动物。
   - `sets61_crowds.tsx`：群众。
   - `sets61.tsx`：总出口，加目录登记表 `ITEMS`、出处短标签 `SRC`。
   - `setsbook61.tsx`：三个合成。
7. **复用**：有几件直接包了 ep60 已有的画法，画面与 ep60 一致：
   - `CanopicSet` ← `CanopicJar`；`SunBarque` ← `Barque`；`Skiff61` ← `Skiff`；`LionBed` ← `LionBier`。
   - `CrocWater` ← `Croc`；`Cow` ← `Ox`。
   - `FlameFx` / `DustMotes` / `Sparks` ← `Flame` / `Dust` / `Embers`。
   - 群众全部用 ep60 神骨架 `God`。

## 1. 分层规则（怎么搭一个场景）

从后往前画，每层一个 `<g>`：

| 层 | 放什么 | 规则 |
|---|---|---|
| 天 | `NightSky` / `HorizonSun` / `RedSky` / `Nun` | 铺满画面上部，最先画。 |
| 远景 | `Pyramids`、`Dunes`、`Pylon`、`DatePalm`、`Geese`、`BirdsCrossing` | 比例小（s ≈ 演员 s 的 0.25–0.7）。夜景加一层压暗（multiply，35–45 %），让角色跳出来。 |
| 中景 | `Obelisk`、`SphinxAvenue`、`Column61` + `Architrave`、`Naos61`、`Nile`、`CrocWater`、`Skiff61`、远处的 `PriestProcession` | 中景群众用演员 s 的 0.6–0.7，站在比前景高 20–30 px 的地线上。压暗 20–25 %。 |
| 地面线 | 一条墨线 + 地面色块（ep61 地线 y = 868） | 角色和前景道具都站在这条线上。 |
| 前景 | `OfferingPile`、`IncenseStand`、`Brazier61`、`OilLamp`、`CanopicSet`、`BeerJars`、小动物、`PapyrusThicket`（可以出画） | 与演员同 s 或稍大。**不要挡住角色的脸和手。** |
| 角色 | `God61` / `Actor` | 同一个 s。 |
| 光 | `Glow`（火盆、灯、门内）、`LightShafts`、`Dust` / `DustMotes`、`Sparks`、`WaterShimmer` | 最后画，用 screen 混合，不被压暗层影响。 |

**其他规则**：

- **有火就要有光**：每个 `Brazier61` / `OilLamp` / `IncenseStand` 旁边加一个 `Glow`（r ≈ 6–8 × s）。
- **一画面一个焦点**：布景的饱和度和细节不能超过角色。远景与中景压暗，前景道具分到画面两侧。
- **群众不能整齐**：同一画面两组群众，`seed` 要不同；`march` 同向时速度差 10–20 %。
- **比例**：建筑可以按“神庙尺度”放大（塔门 28 格高 = 1.4 个人），但同一层里的东西用同一个 s。
- **水最后盖地平线**：`Nile` 画在岸之后，水线压住岸边。纸草丛从画面下沿长出来（y = 画面底），可以被裁掉一半。
- **夜景**：天和远景用 night 色，地面偏紫灰（`#3A2E4A` / `#4A3A40`），火盆是唯一暖色。
- **愤怒**（Sekhmet / Set）：用 `RedSky` 替换天空，`pulse` 跟着鼓点；这是设计选择，不是文物色。

## 4. 已知的限制

- 群众用的是完整神骨架，每人约等于一个角色的渲染开销。一画面超过 ~20 人会变慢，远处群众可以改用更小的 `s`。
- `Cow` 沿用 ep60 `Ox`，牛头偏小、像羊；`Colossus` 是侧面坐像，没有正面版。
- 抬船队列里，船和抬杠的距离是固定的（船立在两根金色支柱上）。要换成船底直接压在杠上，需要另画。
- 氛围层（第 6 页）在 px 空间里，不跟随 `Stage60` 的镜头缩放；放进 `Stage60` 时要放在 `light` 层（世界坐标）里用。
