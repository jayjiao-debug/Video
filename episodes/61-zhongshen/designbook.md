## 0. 全系列通用规则

1. **一副骨架**：所有神与凡人共用 ep60 的 `rig60.tsx` 骨架：单位 = 1 个方格，脚底 y=0、膝 6、髋 9.5、肩 16；阿尼连假发实测 **20.1 格**。同一个 `s`（px/格）画出来就是同一身高 → **神 = 凡人 × 1.00（身体）**。神靠头（豺/朱鹮/隼/狮/猫/Set 兽）、头饰、手里的东西来辨认，不靠变高。
2. **含头饰的总高**（渲染后量出，格；÷20.1 = 倍数）：阿图姆 23.0（×1.14）；拉 21.7（×1.08）；舒 22.2（×1.10）；泰芙努特 21.7（×1.08）；盖布 19.9（×0.99）；努特 21.4（×1.06）；奥西里斯 24.2（×1.20）；伊西斯 21.9（×1.09）；赛特 21.4（×1.06）；奈芙蒂斯 21.6（×1.07）；荷鲁斯 23.0（×1.14）；阿努比斯 21.5（×1.07）；托特 21.8（×1.08）；塞赫迈特 21.7（×1.08）；巴斯特 21.0（×1.04）；玛阿特 22.2（×1.10）；阿尼 20.1（×1.00）。
3. 例外只有两种：孩童荷鲁斯（ep61 镜 14）= 同骨架 ×0.75；特写时整体放大（所有人一起放大，比例不变）。阿米特是非人形的独立小骨架，不与人形比身高：ep60 称重厅里阿米特 s = 34～42，阿尼 s = 26（≈ ×1.3～1.6）。
4. **画法**：头侧面、肩正面、腿侧面（埃及正统）；墨线外轮廓（`OW = 2.7/s`）、扁平填色、不画手指甲；手握物体时“拳头盖在物体前面”（`FingersOver` / `FistOver`）；金/青金/赤陶/墨线是主色。
5. **表情只画骨架真能做的**：眼（睁/半/闭、看向）、眉（扬/皱）、嘴/下颌/喙（闭/半张/大张）、耳（前/平/后）、人脸微笑；见下“表情部件”。

## 2. 角色

出处标签写法：I 行 = `episodes/61-zhongshen/facts.md` 里的 iconography 表（物件 · 博物馆 · 编号）；F 行 = 同文件/ep60 facts 的事实表。“设计选择”= 查不到已核实的上色/细节、由本系列决定；这些都在设定图上标了“设计选择/未核实”。

### 01. 阿图姆 · 拉 · 创世之神 / 太阳神  （Atum · Ra (Re-Horakhty)；SHEETS61 帧 1）

- **一句话**：从黑水里自己站起来的第一位神 · 日出的隼
- **考据（已知的图像证据）**：**阿图姆**（I1）：人形、有须；戴 pschent（红白双冠）；站姿，羽毛胸甲、短裙、兽尾、卷曲假胡须；手持 ankh 与 was（记录里两者都列在 Atum 条下）。**拉 / 拉-荷拉赫提**（I2）：隼首，头顶红日轮 + 圣蛇；一手 ankh、一手长杖（Met 22.3.31 看到）；肤色并不统一（22.3.31：橙红身体、绿松石领与裙、黄色围布、深色隼头金眼；22.3.34：金黄身体、红色披肩领、隼头深色白脸）。**没有逐像上色的 Atum**（Louvre 只给整块碑的颜色），所以他的肤色是本系列的设计选择（与 ep60 男神同为赤陶红）。
- **出处**：I1 · Louvre E 52（Stele of Taperet，也编 N 3663）；I2 · Met 22.3.31（Stela of Saiah）、Met 22.3.34（Djedbastet 拜 Re-Harakhty-Atum）
- **画法 / 部位**（设定图上的引线标注）：红白双冠——阿图姆：上下埃及合一的 pschent〔I1 · Louvre E 52（塔佩瑞特碑）〕；隼首 + 日轮——拉：隼头、红日轮 + 圣蛇〔I2 · Met 22.3.31 / 22.3.34〕；人脸 + 卷胡须——阿图姆人形、戴假胡须（卷须）〔I1 · Louvre E 52〕；ankh + was——一手生命符、一手权杖〔I1 · I2（22.3.31）〕；宽领——金·青·红·绿松石多排宽领〔I2 · Met 22.3.31 绿松石领〕；皮肤——赤陶红（设计选择：未找到逐像描色）〔I1 注：Louvre 仅给全碑色〕；兽尾 + 亚麻裙——腰后兽尾、亚麻褶裙、金腰带〔I1 · Louvre E 52〕
- **色板（hex 来自代码）**：赤陶肤 `#B5502C`、拉 · 隼头 `#3F7186`、红冠/日轮 `#B8371F`、白冠/亚麻 `#F8F3E7`、金 `#ECB637`、青金 `#2E58A6`、绿松石 `#36A39B`、墨线 `#2A1912`
- **比例 / 身高**：神 = 凡人 × 1.00（同一骨架）；阿图姆 23.0 格（×1.14）；拉 21.7 格（×1.08）
- **标志动作**：阿图姆：双臂展开（创世）；拉：隼鸣（头后仰、喙张开）
- **关键姿势**：阿图姆 · 站立、阿图姆 · 行走、拉（隼首）· 站立、拉 · 隼鸣（标志动作）；**压力姿势**：手臂全抬、大跨步、拉 · 头后仰 + 喙张开
- **关节**：颈/头 · 肩/肘/腕 · 髋/膝/踝；隼喙下颌（拉）
- **必须**：阿图姆是人头、有胡须，戴红白双冠；拉是隼头 + 头顶红日轮缠圣蛇；一手 ankh、一手 was 权杖；手不画指甲；两位共用一副骨架，身高同普通神
- **不要**：不要把拉画成人头，也不要给阿图姆画隼头；不要画成两顶分开的冠（红白必须是一顶）；日轮不要画成金色（是红色）；不要给手指画指甲

### 02. 舒 · 空气之神  （Shu；SHEETS61 帧 2）

- **一句话**：撑起天空的神 · 头顶一根鸵鸟羽毛
- **考据（已知的图像证据）**：人形（Ranke：“Always human”）；头顶一根鸵鸟羽毛 = 他名字的象形字（“常见”，并非所有物件都有；Met 04.2.372 的 Shu 护身符据搜索摘要是日轮，**未打开核实**）；标志姿势是双臂高举托住努特（Louvre N 3293：“Shu debout, bras levés” 在 “Nout penchée” 之下；BM Greenfield：双手托举）。没有已核实的上色 Shu → 肤色为设计选择。
- **出处**：I3 · H. Ranke, Penn Museum Bulletin XV 2–3 (1950) pp.17–20；Louvre N 3293（Imenemsaouf 神话纸草）；BM Greenfield 纸草
- **画法 / 部位**（设定图上的引线标注）：鸵鸟羽毛——头顶一根羽毛 = 他名字的象形字〔I3 · Ranke，Penn Museum Bulletin XV (1950)〕；人头——永远是人形（Ranke：“Always human”）〔I3 · Ranke 同上〕；托天——双臂高举撑住努特〔I3 · Louvre N 3293（Shu debout, bras levés）〕；皮肤——赤陶红（设计选择：无已核实的上色 Shu）〔I3 注〕；短发 · 无假发——设计选择：不戴三段假发，让羽毛清楚〔cast61 · CAST61.shu〕
- **色板（hex 来自代码）**：赤陶肤 `#B5502C`、亚麻 `#F8F3E7`、金 `#ECB637`、青金 `#2E58A6`、红 `#B8371F`、绿 `#3A9160`、墨线 `#2A1912`
- **比例 / 身高**：神 = 凡人 × 1.00（舒 S=27～30 与全片同比）；总高 22.2 格（×1.10）
- **标志动作**：双臂高举托天
- **关键姿势**：站立、行走、托天（标志动作）、风 · 双臂展开；**压力姿势**：双臂全抬（托天）、大跨步、头后仰（托举用力）
- **关节**：双臂可全抬 170°；脊柱后仰；膝踝承重
- **必须**：头顶一根直立的鸵鸟羽毛；托天时双臂伸直、掌心朝上、脚踩实；人头人身，不带动物特征
- **不要**：不要给舒画狮头（那是泰芙努特）；羽毛不要画成两根或斜插；托天时不要让手臂穿过头部

### 04. 盖布 · 大地之神  （Geb；SHEETS61 帧 4）

### 05. 努特 · 天空女神  （Nut；SHEETS61 帧 5）

- **一句话**：弯下身体的夜空 · 身上是星星
- **考据（已知的图像证据）**：女性，裸身，弯成拱形罩在大地上（Louvre E 52：“Nout (femme, nu, penché, soleil, étoiles)”）；Met 96.4.4 上看到：蓝色天拱，黑假发的头在右上、脚在左下、手在右下，**那件上没有星**。头顶红色 nu 罐（I6 标 unverified）→ 设计选择。站立形态（ep61 cast61.nut）= 女性身体 + nu 罐 + 窄身长裙；拱形态 = `NutArch`（星拱 + 头 + 触地的手脚）。
- **出处**：I6 · Louvre E 52；Met 96.4.4（Tabakenkhonsu 木板画，c.680–670 BCE）
- **画法 / 部位**（设定图上的引线标注）：红色 nu 罐——头顶红色 nu 罐（设计选择，I6 标 unverified）〔I6 · 未核实〕；弯身成拱——头在一端、手脚触地；身上是星星（见标志动作格）〔I6 · Louvre E 52（Nout penchée…étoiles）〕；蓝色天拱——星拱用青金蓝〔I6 · Met 96.4.4〕；皮肤——黄赭（女性惯例）〔cast61 · nut〕；窄身长裙——站立时红裙（设计选择；拱形态为裸身）〔I6：“femme, nu”〕
- **色板（hex 来自代码）**：女性肤 `#E3A94E`、星空蓝 `#1D2E6E`、星金 `#F2C649`、nu 罐/裙 `#B8371F`、黑发 `#1E1A1B`、金 `#ECB637`、青金 `#2E58A6`、墨线 `#2A1912`
- **比例 / 身高**：神 = 凡人 × 1.00；拱形态按画面比例（手脚到手脚 = 拱宽）；总高 21.4 格（×1.06）
- **标志动作**：弯身成拱，身上是星星

## 5. 以后每一集怎么用

```tsx
// 骨架与 ep60 五神（阿努比斯、托特、奥西里斯、荷鲁斯、伊西斯）+ 阿尼
import {God, CAST, POSES, Pose, solve, reach, holdAt, wristTo} from '../qq60/rig60';
import {ANI, walkPose, ANI_POSES, CAST2} from '../qq60/cast60';        // 阿尼的走/跪/举臂/被审判/收割；ep60 的拉、塔图…
// ep61 全体神（含 ep60 那几位，原样复用）
import {God61, CAST61, P61} from '../qq61/cast61';                   // P61.rest / lift / wide / menace / roar / lick / shake
// 带表情层的演员（= God61 + 眼/眉/笑/嘴 + 手持羽毛）
import {Actor} from '../qq61/sheetkit61';
// 非人形与道具
import {Balance2} from '../qq60/act60b_kit';  import {Ammit61} from '../qq61/ammit61';  import {MaskFront, GoldDefs} from '../qq60/act60a_kit';  import {Feather} from '../qq60/props60';  import {HeartScarab} from '../qq60/props60b';
```

- **谁用哪个组件**：阿图姆/舒/泰芙努特/盖布/努特/伊西斯/赛特/奈芙蒂斯/塞赫迈特/巴斯特/玛阿特 → `God61 who="…"`（key：`atum shu tefnut geb nut isis set nephthys sekhmet bastet maat`）；拉/阿努比斯/托特/奥西里斯/荷鲁斯 → `God61 who="ra|anubis|thoth|osiris|horus"`（内部就是 ep60 的 `God` + `CAST`，一模一样）；阿尼 → `God cast={ANI}` 或 `God61 who="ani"`；阿米特 → `Ammit61`（ep60 旧片里仍是 `Ammit2`，不要改它）。
- **比例**：一个场景里所有人形用**同一个 `s`**（px/格）。想让谁显得大，靠镜头/构图，不要改单个角色的 `s`；孩童荷鲁斯 = `s × 0.75`。
- **标志动作**：直接用本册给的姿势：`POSES.write`（托特）、`POSES.kneel` + `reach`（阿努比斯跪秤）、`POSES.throne` + `mummyHands`（奥西里斯）、`POSES.protect`（伊西斯展翼）、`P61.lift`（舒托天）、`P61.roar` + `roar={1.3}`（狮首怒吼）、`P61.lick`/`P61.shake`（巴斯特）、`P61.menace` + `sneer`（赛特）。每张设定图第 3 个关键姿势就是它们。
- **表情**：`<Actor … look={{eyes: 0.5, brow: -1}} jaw={1} ear={24} />`；动画里把这些数字当关节随时间插值即可（`RIGTEST61` 就是这么做的，见 `sheets61.tsx · RigTest`）。
- **新角色 / 改角色**：先改 `cast61.tsx`（`CAST61`）和 `chars61.tsx`（设定表数据），重新渲染 `SHEETS61`，**肉眼过一遍对应那张表**再用到影片里。不要在影片里另画一个“差不多的”神。
