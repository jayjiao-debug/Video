# ep20 · 《窄门》：人该追求快乐，还是追求意义？ — 脚本 v0（2026-10-10）

**一句话：** 1947年诺贝尔文学奖得主纪德，写了一个对爱人说"我们生来不是为了幸福"的女人。斯坦福等学者的研究发现，快乐和意义确实不是一回事。可她把意义推到了极端，最后把自己耗干了。
**观众带走：** 意义不是幸福的敌人；只要其中一个，都会出问题。
**时长 / 音乐：** 130 秒，用系列原曲 s130f，不剪。标题在第 8 小节（0:16.6），大 drop 在第 40 小节（1:21.4），片尾卡 2:05.4。每句 4 秒，卡在小节线上。
**画面方向：** 系列固定风格，夜蓝 + 金。每个镜头只点亮一个主体：
- 花园里的玫瑰；
- 那枚紫水晶十字架（他送的，后来成了"你明天该走了"的暗号）；
- 日记页，字一行行写出来；
- 研究数据做成"快乐 / 意义"左右分屏的动态点阵；
- 结尾仆人端进来的那盏灯。

人物全部是无脸剪影。
