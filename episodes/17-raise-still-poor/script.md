# 《工资涨了，为什么还是觉得穷？》脚本 v0

**时长：** 约 2:00，纯字幕，跟着音乐走
**视角：** 第一人称，你自己的手机：银行短信、工资条、群聊
**看完会发给谁：** 一起抱怨工资的同事，或者刚涨薪的朋友

> 标「待核实」的数字，研究员下一步会去查原文确认。没核实过的数字不会进片子。

---

## 场景 1　开场：工资到账（0:00–0:16）

**开场画面：** 手机锁屏，一条银行短信在第 0 帧弹下来：「您尾号 8826 的账户 工资收入 **¥9,800.00**」。旁边一个小角标写着「比去年 **+1,200**」。

| 时间 | 字幕 | 画面 |
|---|---|---|
| 0:00 | 涨薪了，每月多了1200 | 短信弹出，数字一跳 |
| 0:03 | 开心了大概……三天 | 屏幕上的日期翻过三天 |
| 0:06 | 然后你刷到同事的朋友圈 | 朋友圈里，同事晒出新车钥匙 |
| 0:09 | 他涨了**3000** | 一条消息：「年终调薪 +3000 🎉」 |
| 0:12 | 你的1200，突然**不香了** | 你那条短信的颜色一下变暗 |

**片名，落在音乐进拍上（约 0:16）：** 工资涨了，为什么还是觉得穷？

## 场景 2　你更想要哪个世界？（0:20–0:48）

**开场画面：** 画面一分为二，两扇门。左门上写「你挣 5 万，别人挣 2.5 万」，右门上写「你挣 10 万，别人挣 20 万」。一个光标停在两扇门中间。

| 字幕 | 画面 | 事实 |
|---|---|---|
| 哈佛的研究者问过一个问题 | 两扇门亮起 | Solnick & Hemenway 1998（待核实） |
| A：你5万，别人2.5万 | 左门，你的柱子比别人高 | |
| B：你10万，别人20万 | 右门，你的柱子是左边的两倍，却比别人矮 | |
| B 明明多挣一倍 | 右门的柱子发光 | |
| 可大约**一半的人**选了 A | 左门前的人群排起长队，数字慢慢滚到一半左右 | |
| 我们要的不只是钱 | 柱子之间画出一条比较线 | |
| 是**比别人多** | 比较线变红 | |

## 场景 3　真实发生的一次"工资公开"（0:48–1:12）

**开场画面：** 一个新闻网站页面，标题是「本州公职人员工资，全部可查」，下面一个搜索框，一只光标正在输入同事的名字。

| 字幕 | 画面 | 事实 |
|---|---|---|
| 2008年，美国一家报纸 | 网页亮起 | Card、Mas、Moretti、Saez 2012《AER》（待核实） |
| 把大学员工的工资放上了网 | 一排排名字和工资滑过 | |
| 谁都能查到同事挣多少 | 光标点开一个同事 | |
| 发现自己**低于中位数**的人 | 一条线把名单分成上下两半，下半部分变暗 | |
| 满意度下降，更想跳槽 | 下半部分的人头上冒出「找工作」小图标 | |
| 高于中位数的人呢？ | 上半部分 | |
| **并没有更开心** | 上半部分没有任何变化 | |

## 场景 4　再加一招：涨薪的"幻觉"（1:12–1:36）

**开场画面：** 两张并排的工资条：小A「涨薪 2%，物价没涨」，小B「涨薪 5%，物价涨了 4%」。

| 字幕 | 画面 | 事实 |
|---|---|---|
| 再看两个人 | 两张工资条 | Shafir、Diamond、Tversky 1997（待核实） |
| 小A：涨2%，物价不变 | 小A的购物车多装了一点 | |
| 小B：涨5%，物价涨4% | 小B的购物车几乎没变 | |
| 谁更开心？ | 两个人头上各一个问号 | |
| 大多数人说：**小B** | 小B头上亮起笑脸 | |
| 可实际能多买的，是小A | 小A的购物车更满，用一把尺子量给你看 | |
| 我们看的是数字，不是能买什么 | 数字和购物车分开 | |

## 场景 5　结尾（1:36–2:00）

**开场画面：** 回到第一帧的那条短信「工资收入 ¥9,800.00」，周围的朋友圈都慢慢淡出，只剩这一条。

| 字幕 | 画面 |
|---|---|
| 所以觉得穷，不一定是钱少 | 只剩你的那条短信 |
| 是你在跟谁比 | 同事的朋友圈淡出 |
| 下次涨薪，先别急着打开朋友圈 | 你把朋友圈的红点划掉 |
| 先看看：它能让你多做点什么 | 1200 变成：一次周末旅行、一堂课、存下的一笔钱 |
| 你上一次涨薪，开心了几天？ | Juno 片尾卡 |

**片名备选：**
1. 工资涨了，为什么还是觉得穷？（每个打工人都问过自己）
2. 多挣一倍你不要，只要比别人多？（用实验当钩子）
3. 涨薪的开心，为什么只能撑三天？（说出那种感受）

**我更推荐这一集的原因：** 第一帧（工资到账短信）和场景 2（两扇门选一个）几乎不用解释，观众能马上代入自己，还会想在评论区说自己选 A 还是 B。
