# Script: 你的童年记忆，可能是假的 — v1 (2026-10-20)

**Spine:** a hook on the viewer's own first memory → why (recall = rewrite) → three experiments that change memory, each bigger than the last (a word → a photo → a whole childhood) → the twist: the replication and reanalysis score the famous result down → what really changes is detail and confidence → why it matters (eyewitnesses) → takeaway.
**Takeaway:** 记忆不是录像，是每次重写的草稿。整段造假很难；被改的，是细节和你的确信。
**Length:** ~2:05 (times provisional until the music is chosen; ~2.8 s per line).
