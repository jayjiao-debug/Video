# 《已读不回》脚本 v0

**题目：** 对方"已读不回"，为什么这么难受？
**时长：** 约 2:00，纯字幕，跟着音乐走
**视角：** 第一人称，你自己的手机屏幕
**看完会发给谁：** 那个总是已读不回的人

> 标「待核实」的数字，研究员下一步会去查原文确认。没核实过的数字不会进片子。

---

## 场景 1　开场：你发出去的那句话（0:00–0:16）

**开场画面：** 整个画面就是一部手机的聊天窗口。你刚发出一句「在吗？明天有空吗」。第 0 帧，气泡就在"嗖"一下飞上去。

| 时间 | 字幕 | 画面 |
|---|---|---|
| 0:00 | 你发了一句「明天有空吗」 | 气泡发出，旁边的小字从「送达」变成「已读」 |
| 0:03 | 显示：**已读** | 「已读」两个字放大 |
| 0:05 | 然后，**什么都没有** | 输入框空着，右上角的时间一分钟一分钟往上跳 |
| 0:09 | 10分钟，30分钟，2小时 | 时间快进；你退出聊天，又点回去 |
| 0:13 | 你开始想：我说错什么了？ | 你自己的输入框里打了字又删掉 |

**片名，落在音乐进拍上（约 0:16）：** 已读不回，为什么这么难受？

---

## 场景 2　被冷落，大脑当成了"疼"（0:20–0:44）

**开场画面：** 手机屏幕往后退，变成一个三个人互相抛球的小游戏界面。三个圆头小人，球在其中两个之间来回，你那个一直接不到。

| 字幕 | 画面 | 事实 |
|---|---|---|
| 心理学家做过一个小游戏 | 三人抛球 | Cyberball，Williams 等 2000（待核实） |
| 三个人抛球，抛着抛着 | 球开始只在另外两人之间来回 | |
| 另外两个人，**不再抛给你** | 你的小人站在原地，手举着 | |
| 只是一个电脑游戏 | 角落里写着「对方是电脑程序」 | |
| 可大脑里亮起的区域 | 画面切到大脑剖面，一块区域亮起来 | Eisenberger 等 2003《Science》（待核实） |
| 和**身体疼痛**时很像 | 旁边对照一张「手被烫到」的亮区 | |

---

## 场景 3　最难受的，是"不知道"（0:44–1:08）

**开场画面：** 回到你的聊天窗口，「已读」下面出现两个选项：「他不想理我」「他只是在忙」。指针在两个选项之间来回晃。

| 字幕 | 画面 | 事实 |
|---|---|---|
| 其实最难受的，不是被拒绝 | 两个选项晃来晃去 | |
| 是**不知道**被没被拒绝 | 两个选项都变灰，问号放大 | |
| 有实验让人等一下电击 | 一根进度条：「可能电击 50%」 | de Berker 等 2016《Nature Communications》（待核实） |
| 「一定会电」反而没那么紧张 | 进度条到 100%，心率曲线变平 | |
| 「也许会电」最紧张 | 进度条停在 50%，心率曲线乱跳 | |
| 已读不回，就是那个 **50%** | 进度条变成你的聊天窗口 | |

---

## 场景 4　反转：他可能真的只是没觉得急（1:08–1:36）

**开场画面：** 画面分成左右两半：左边是你盯着屏幕，右边是对方的手机：你的消息压在一堆群消息下面，他正在地铁里，屏幕一滑就过去了。

| 字幕 | 画面 | 事实 |
|---|---|---|
| 换到对方那一边看看 | 左右分屏 | |
| 你的消息，在他那儿是这样的 | 被 99+ 的群消息压在下面 | |
| 研究发现：发消息的人 | 左边的你在倒计时 | Giurge & Bohns 2021（待核实） |
| 总以为对方**应该马上回** | 你的计时器飞快地转 | |
| 收消息的人觉得：**不急** | 右边他的计时器慢悠悠 | |
| 你等的那2小时 | 两边的时间轴并排放 | |
| 他可能根本没当成一件事 | 他的那一边，你的消息只占一小格 | |

---

## 场景 5　结尾（1:36–2:00）

**开场画面：** 回到第一帧那个聊天窗口，同一个「已读」。这次你没有打字也没有删，而是把手机扣在桌上。一束暖光打进来。

| 字幕 | 画面 |
|---|---|
| 所以下次看到「已读」 | 同一个「已读」 |
| 那阵难受，是大脑在报警 | 心率曲线慢慢平下来 |
| 不是你说错了什么 | 你把手机放下 |
| 只是，**还不知道而已** | 手机亮了一下：对方回了「明天可以呀」 |
| 你有没有一个，总已读不回的人？ | Juno 片尾卡 |
