## Builder rules (everyone)

- **Engine:** `film/lib.mjs` (camera `L()`, `kf/ramp/zexp/E`, `bake()`, `snow/motes/embers/flames`, `wipeMask`,
  `vtext`, `palmPrint`, `jseal`), `film/film.mjs` (take contract), `film/render.mjs` (stills / sheet / video). Read
  them first. Do not edit lib.mjs, film.mjs, render.mjs or subs.mjs: if you need a change there, send the main
  agent a message (SendMessage to "main"); put your own helpers in your take file or in a `film/cast/*.mjs` you own.
- **Take file:** `film/takes/tNN.mjs` default-exports `{ frame(t), enter?, subYc?, noBrand? }` (t0/t1 come from
  film.mjs). `frame(t)` returns SVG content in 1920×1080 user space. It must also render for t a little outside its
  window (transitions). Prefix every SVG id with the take id (`t05sky`) so takes can be drawn together.
- **Characters:** 林冲 = `lin()` from `chars/rig/linchong.mjs` (API in its header; costume A 东京 green; convict =
  A with `col:{robe:'#3B4356'}`, `headCloth:'plain'`, `cangue:true`, `tattoo`; costume C = snow look with the 毡笠,
  brown cloak, spear + gourd). The rig is still being polished by the rigger (sleeves, close-up faces): call it, don't
  copy it, so improvements flow in. For close-ups, draw lin() large (height 2000–4000) and frame the face.
  Secondary characters: draw them in the same flat cel style (brown line #2A1C17, two-tone cel shading); keep them
  partial (OTS, backs, hands, silhouettes, shadows) where the storyboard allows. **The wife's face is never shown.**
  Every visible face carries `<rect data-face="1" …>` (the rig does this; add it for your own characters).
- **Layout:** no face in the subtitle band (y 820–960); in-picture text and calligraphy in y 100–780; the top-left
  420×200 calm; nothing important within 120 px of the left/right edges. Backgrounds cover the full frame at every
  camera position (overscan) — mark full-frame backgrounds `data-cover` via `L(..., {id:'bg', bleed:'all'})` and
  check. No black screens; mean luma per colour script.
- **Motion:** every shot moves (camera drift + an acting beat). Speed limits: ≤ 25 px/frame for any layer, ≤ 16 for
  the subject plane; no whip pans; shake only on the element that hits (≤ 4 px, 2–4 frames). Hits land on the
  listed times. Continuous actions (walks, steam, snow, flicker) run on their own clocks, not on the beat.
- **Performance:** heavy static art (sets, crowds, mountains) goes through `bake()` (rendered once to PNG). Avoid
  big blur filters on per-frame layers; bake blurred backgrounds instead. Target ≤ 0.6 s/frame.
- **Care:** no gore, no blood, no weapon striking anyone; the killing is never shown; real-era props only; no
  copyrighted characters or artwork; no Western items.
- **Checks:** `node film/render.mjs stills <dir> t1,t2,…` (prints automatic checks) and `node film/render.mjs sheet
  <out.jpg> <t0> <t1> 0.5`. Look at your stills yourself (Read the jpgs) at every hit and every transition, at
  full size for faces and hands. Fix proportions (model_sheet.md), contact (hands touch what they hold), layering
  (nothing in front that should be behind), clipping at the frame edge and at the take boundaries.
- **Files you may write:** your take files, `film/cast/<yours>.mjs`, scratch output under `/dev/shm/shz01/film/`.
  Commit only your own code files (never images, audio or video):
  `git add <your files> && git commit -m "…" ` with the session attribution lines, retrying if `index.lock` is busy;
  then `git pull --no-rebase --no-edit && git push`. No amend, no rebase.
